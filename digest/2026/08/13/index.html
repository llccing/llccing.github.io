Angular

Angular 发布了 21.2.20，核心侧修复了在具体宿主上对 host bindings 的 sanitize，HTTP 侧则在删除时改为精确匹配 header 值 [1]。VSCode 扩展同步更新到 22.1.0：语言服务修复了默认启用 strictTemplates 时的处理，并新增对需要内联 typecheck blocks 的模板类型检查，以及在 standalone 场景下编译非导出类的能力 [2]。这些改动直接关系到模板类型安全与宿主绑定/请求头行为的正确性。

AI

DeepSeek V4 Pro 0813 已通过 OpenRouter 以 API 形式提供；Simon Willison 指出官方暂无明显发布页，且鉴于此前 V4-Pro 与 V4-Flash 均有权重开放，后续开源权重的可能性较高，他还观察到不同 reasoning 级别生成结果差异明显 [3]。他同时发布了 alchemy-utils 0.1a0 原型，目标是用 SQLAlchemy 复现 sqlite-utils 的 insert/upsert/create/update 与表内省等核心 API，以覆盖 PostgreSQL、SQLite 等多引擎 [4]。Vercel AI SDK 分别发布了 ai@5.0.235 与 ai@6.0.253，后者保留 UI 消息流中 reasoning 块 ID [5][6]。OpenAI 则分享了企业采用 agentic AI（ChatGPT、Codex）的研究，以及 RingCentral 用 ChatGPT Work 与 Codex 加速产品与运营智能化的实践 [7][8]。Sophie Alpert 强调自然语言文本不存在无损变换，工程师必须对文档中每一观点与句子负责 [9]。
