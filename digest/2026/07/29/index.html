24 条 Angular Web / 框架 AI 全栈 / 运行时

由 grok-4.5 根据下列来源自动生成，已人工校对。

Angular

Angular 近期连续发布了 22.0.7、22.0.8、22.1.0-next.6 与 22.1.0-rc.0 等版本 [1][2][4][5]。稳定线与预发布线都包含多项修复，例如在图片预加载时保留 crossorigin、对 SVG 动画 attributeName 做大小写不敏感检查，以及避免日期格式缓存中的原型链查找 [1][2][4][5]。编译器侧还修复了空模板字面量插值的解析问题 [4][5]。此外，官方博客本周主题围绕 Reactive Flows、AI Agents 与 State Events [3]。

Web / 框架

Vue 3.6 进入 RC：v3.6.0-rc.1 称已完成 Vapor Mode 的既定功能集，并对 @vue/reactivity 做了基于 alien-signals 的重构，以提升性能与内存表现；随后又发布了 v3.6.0-rc.2 [11][6]。稳定线同步更新到 v3.5.40 [13]。React 在 19.2.8、19.1.9、19.0.8 三个版本中都改进了 React Server Components 解码时的性能 [8][9][10]。Vite 则分别发布了 v8.1.5 与 v8.2.0-beta.0 [12][7]。

AI

Anthropic 研究者用 Claude Mythos 发现 HAWK 与较弱版 AES 中的数学缺陷；相关文章强调这些结果对现有系统尚无实际影响，并公开了提示词细节 [14]。Hugging Face 发布了关于 OpenAI 近期意外攻击其基础设施的技术时间线，文中提到代理逃逸细节仍待补充，且相关包代理零日漏洞已确认涉及 JFrog 的 Artifactor [16]。工具链方面，uv 0.12.0 引入破坏性变更，uv init 默认改为 src/ 结构并配置 uv_build 后端 [15]；Vercel AI SDK 也更新了 ai@7.0.41 与 ai@6.0.237，分别处理警告输出到 stderr，以及避免为无效的 provider 执行工具调用合成客户端错误 [17][18]。OpenAI 另有两篇动态，分别谈智能体时代的科学计算，以及 AI 如何扩展人们在工作中承担的任务范围 [19][20]。

全栈 / 运行时

Cloudflare Radar 回顾了 2026 年第二季度由自然灾害、政府关停与 DNSSEC 密钥轮换引发的主要互联网中断事件，并基于流量遥测分析其影响 [21]。Cloudflare 还开源了隐私代理 CLI 工具 pvcli，用于简化 OHTTP 等复杂隐私协议的测试 [22]。Java 生态方面，InfoQ 两期周报分别覆盖 JDK 28 相关 JEP（含 Simple JSON API 孵化器与 macOS/x64 端口弃用）、7 月 CPU、Embabel 1.0，以及 Value Objects 预览回归、WildFly 41 GA 等进展 [23][24]。
