AI

Graham Dumpleton（wrapt、mod_wsgi 及 New Relic Python agent 作者）推出 Wrapture，将 wrapt 的 monkeypatching 思路同时延伸到测试与追踪：可包装任意函数或方法，使全部访问可被追踪，或被覆盖为返回不同值 [1]。Vercel AI SDK 连续发布补丁：ai@7.0.86 为 WorkflowAgent 增加签名工具审批支持，并更新依赖 @ai-sdk/gateway@4.0.70；ai@7.0.87 修复 UI 消息流中审批描述符未能保留的问题 [3][2]。OpenAI 表态支持加州 SB 1119，推动面向青少年的适龄 AI 安全措施，同时保留学习、创作与探索空间 [4]。日本 Polimill 使用 OpenAI GPT 模型与 Codex，帮助自治体检索并利用行政知识、加速开发，以建设下一代公共 AI 基础设施 [5]。

全栈 / 运行时

Cloudflare 推出 Adaptive Intelligence 引擎，试图扭转机器人攻击的经济优势：以往攻击者可用廉价代理和快速改工具绕过静态、确定性检测规则；新引擎从实时流量的元信号自主学习并部署一次性规则，使自动化攻击难以持续 [6]。InfoQ 汇总 2026 年 8 月 24 日当周 Java 动态：Atmosphere 4.0 正式发布；GraalVM、Azul Payara、Quarkus 有点版本更新；WildFly 41 维护版；Jakarta Data 与 Eclipse JNoSQL 里程碑版；Open Liberty 2026 年 9 月版进入 beta；GlassFish 8.0.4 发布 Docker 镜像 [7]。
