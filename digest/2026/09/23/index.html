Anthropic 发布了 Claude Opus 5.5，约一小时后 OpenAI 发布 GPT-6 Sol 与 GPT-6 Luna；前一日还有 Grok 4.7 和 MiMo v2.6 Flash/Pro，Simon Willison 将其与新一轮价格战并提，并指出需要一段时间才能对这些新模型形成可靠判断。[1][5] OpenAI 称 Sol 与 Luna 以不同的能力与成本配比把前沿智能带到日常工作，同时 GPT-6 改进了 prompt caching，具备更高缓存命中率、新诊断、显式断点以及可降低延迟与成本的控制项。[5][2] llm 0.36 新增 gpt-6-sol 与 gpt-6-luna，并允许模型插件声明 supports_conversation = False，对仅接受单轮提示的模型抛出 llm.ConversationNotSupported；llm-anthropic 0.29 则加入对 Claude Opus 5.5 的支持。[3][7] Vercel AI SDK 发布 ai@7.0.111，为 experimental_evaluate 增加遥测，并修复 URL 后端语言模型文件输出的安全下载，使生成文件暴露实际 base64 与字节内容、UI 流包含有效 data URL，同时将取消传播到批量文件下载；ai@7.0.110 则更新了 @ai-sdk/gateway 依赖。[4][6]

全栈 / 运行时

Cloudflare 在所有套餐的 Cache Rules 中上线 HTTP Vary 支持，可归一化已知协商头、在细微差异重要时把精确值传给源站，或在变化过于不可预测时绕过缓存。[8] 同期推出的 Worker Previews 为每个分支提供独立 URL、配置、状态与可观测性，使人与 agent 能并行测试变更且不影响生产。[9] Node.js 26.10.0（Current）发布，crypto 新增 crypto.parsePKCS12()，ffi 支持从挂载的 VFS 加载库。[10]
