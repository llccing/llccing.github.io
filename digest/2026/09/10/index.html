技术简报 2026-09-10

18 条 Angular Web / 框架 AI 全栈 / 运行时

由 primary/grok-4.6 根据下列来源自动生成，未经人工校对。

Angular

Angular 同期放出多条版本线。预览版 22.2.0-next.7 没有面向用户的变更[1]；22.2.0-next.6 与稳定版 22.1.6 都修复了 compiler 对 @property 声明的命名空间处理，以及 compiler-cli 在未调用的 track 函数检查中把零参数可调用对象误判为问题的行为[2][3]。20.3.31 则在 platform-server 中将 domino 更新到最新版本[4]。同一批 compiler 修复同时进入预览通道与 22.1 稳定线，说明这些问题已被当作需要尽快对齐的缺陷。

Web / 框架

React 19.3.0 于 2026 年 9 月 9 日发布，官方列出了全部新特性、API 与缺陷修复，其中明确提到新增用于驱动 View Transition 动画的 API，包括 addTransitionType[5]。Vite 发布 v8.3.0-beta.1：devtools 可启用开发服务器集成；构建侧在 resolveFileUrl hook 中保持哈希占位符原样；bundled-dev 在客户端上报时标记 payload 已送达[6]。前者把视图过渡动画收进框架 API，后者在 beta 通道推进开发工具与构建细节修复，都直接关系到前端交互与工程链路。

AI

OpenAI 宣布 Paul Christiano 加入 OpenAI Foundation Board 及其 Safety and Security Committee；Chris Lehane 同时撰文称，更强的 AI 能力需要更强的安全证据、共享标准与持久政策行动，应趁政策窗口仍开放时采取行动[10][11]。ChatGPT Images 2.5 发布，称 ChatGPT Images 与 API 中的 GPT-Image 模型已生成超过 30 亿张图像，新版本提升多轮指令遵循、响应速度和参考照片主体保留，API 新增 gpt-image-2.5-sunburst 与 gpt-image-2.5-flare[13]。另有文章称 OpenAI 使用未发布模型给出了七个千禧年大奖难题之一——Navier–Stokes 存在与光滑性问题——的解答，但该结果在一定程度上被舞弊指控所掩盖[12]。Simon Willison 继续用 GPT-6 Astra 与 Blender 创作，并推出 .blend URL Viewer，同时尝试用新的图像模型制作致敬法贝热彩蛋的作品[7]。Vercel AI SDK 的 ai@7.0.96 与 ai@7.0.97 加入 batch cancel 与 list API，修复 Cloudflare Workers 下 atob 需无 receiver 调用的兼容问题，并在视频 webhook 接收器于生成开始前被拒绝时避免未处理的 rejection，同时保留启动错误优先级、且只纳入一次自定义接收器[8][9]。

全栈 / 运行时

Node.js Current 26.8.2 弃用 node:net 的 Server.prototype._listen2，细化实验性功能的安全漏洞处置姿态，并将 Undici 更新到 8.10.2[14]；LTS 24.21.0（Krypton）把根证书更新到 NSS 3.126、OpenSSL 更新到 3.5.8，并以 SEMVER-MINOR 方式支持通过 STORE loader 加载私钥[16]。Cloudflare 重建 Workers 模块注册表以加强 Node.js 兼容：默认开启 Node.js 兼容、应用体积可达 64 mebibytes，并提供基于 URL 的模块注册表、import.meta、惰性编译、共享代码缓存和更清晰的错误信息[15]；同时推出 Automatic Key Exchange，探测支持 TLS 1.3 的客户源站所支持的密钥协商算法，连接时优先采用最安全算法、并在源站支持时偏好后量子连接，覆盖约 450 亿次每日源站握手[17]。Java 方面，对应 2026 年 8 月 31 日当周的综述包括 TornadoVM 6.0 正式发布，以及 JReleaser、LangChain4j、Java Operator SDK、JHipster、Kotlin Toolchain、Yupiik Fusion 的小版本和 Micronaut、GraalVM Development Kit 的维护版本[18]。
