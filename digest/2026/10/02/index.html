Web / 框架

Vite 发布 v8.3.2，本轮以构建与 bundled-dev 的缺陷修复为主。[1] 当 renderBuiltUrl 返回带查询参数的 URL 时，CSS 预加载现可正确处理；bundled-dev 会提供懒加载 chunk 的 sourcemap，并从已安装的 rolldown 提供 rolldown runtime。[1] 这些问题直接关系到生产构建的资源预加载，以及开发态打包后的调试与运行时来源一致性。

AI

Vercel AI SDK 分别放出 ai@6.0.300 与 ai@7.0.127 补丁。[2][3] 6.0.300 主要是同步依赖 @ai-sdk/gateway@3.0.209。[2] 7.0.127 在工具搜索中支持通过 search() 回调筛选并排序合格的延迟工具，并增加可配置的 maxResults；同时修复消费者断开时未取消合并 UI 消息流，以及接受在另一 JavaScript realm 中创建、内容未变的工具审批输入，依赖更新至 @ai-sdk/gateway@4.0.103。[3] OpenAI 方面，一则讨论高级 AI 对突破性想法背后常规执行工作的意义，以及执行可能如何影响下一轮经济与进步节奏；另一则介绍 Albertsons Companies 使用 ChatGPT Enterprise 与 OpenAI API，加快内部协作并改善数百万顾客的购物体验。[4][5]

全栈 / 运行时

Cloudflare 推出开源决策模型 Clef 与 Clef-flash，托管在 Workers AI 上，面向高速分类与 agentic 工作流，并同步上线强化学习微调平台，开发者可用自有数据微调决策模型。[6] 另有回顾指出：AI 主权并非零和博弈，但许多政府目前如此看待；Cloudflare 的回应是提供更多本地开源模型、与模型无关的安全工具，以及让国家拥有真正选择权。[7] 边缘上的开源决策模型、自有数据 RL 微调，以及主权 AI 相关的产品取舍，是本轮值得关注的运行时动向。
