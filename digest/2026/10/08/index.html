11 条 Web / 框架 AI 全栈 / 运行时

Web / 框架

Vite 相继发布 v8.2.4 与 v8.3.3。[1][2] 材料中 v8.2.4 未给出具体变更说明；v8.3.3 则包含多项缺陷修复，包括将 launch-editor 更新至 v2.14.2、确保传入 transformIndexHtml 的文件名不含查询参数，以及针对 ?vite-wasm-instance 检查 fs.serve。[2] 这些改动覆盖依赖、HTML 转换与开发服务器路径，直接影响日常前端构建与本地开发体验。

AI

Vercel AI SDK 发布 ai@7.0.133，为实验性 decision state 增加有序的 text、file 与 JSON parts，并在 OpenAI Decisions 及语言模型适配器中支持图像输入；Gateway 与 TypeSafe AI 仍沿用既有字符串和 JSON 请求格式并拒绝文件，直接作为 state 传入的数组现包含 decision state parts，公共状态会先规范化为 parts 数组再调用决策提供方，文件字节在 OpenTelemetry 状态中以 base64 序列化。[3] Anthropic 推出快速、低成本的 Claude Haiku 5.5；此前的 Haiku 4.5 已近一年，定价为每百万 token 输入 1 美元、输出 5 美元，即便在当时也相对昂贵。[4] OpenAI 将把 College Planner 引入 ChatGPT for Teens，帮助学生管理大学申请，并伴随闪卡、测验与青少年 AI 理事会；Radisson Hotel Group 与 Accenture 合作，基于 OpenAI 技术构建 ChatGPT 插件，协助旅客在行程规划中查找、比较并预订酒店。[6][7] EmbeddingGemma 2 采用 Apache 2.0 许可，Simon Willison 认为嵌入模型尤其不适合封闭、仅托管的专有方案，因为多数应用需要计算并存储成千上万甚至数百万向量。[8] 此外，Michael Lynch 归纳了软件博客中的反模式，包括离题引言、误判读者既有知识、假定读者读过前文、过度正式，以及用链接代替术语解释。[5]

全栈 / 运行时

Node.js 于 2026-10-07 发布 Current 线 26.11.0 与随后的 26.11.1。[11][9] 26.11.0 的显著变更为 buffer 新增 isLatin1 与 Buffer.stringLength()（均为 SEMVER-MINOR），以及 build、doc 转向 redesign。[11] 26.11.1 则回退了若干构建与文档改动，包括按 V 切换 doc-kit 详细程度、上述 redesign，以及 tools/doc 中 doc 组的 4 项更新。[9] Cloudflare 介绍了构建在 Workers 与全球网络遥测上的证据接地型智能体安全运营体系：Managed Defense 用一组专用 AI 智能体分析安全告警，将确定性证据收集与模型推理分离，向分析师提供有依据的建议。[10]
