AI

OpenAI 与 Le Groupe Figaro 合作，将 Le Figaro 的新闻以摘要和摘录形式引入 ChatGPT，并附原文链接。[1] OpenAI 推出 GPT-6.2 Astra 作为用于最难项目的前沿模型，以及 GPT-6.2 Sol 作为用于日常工作的高效多功能模型，二者在 API 中分别以 gpt-6.2-astra 和 gpt-6.2-sol 提供，Astra 价格为前代的 80%，并在专业输出、编码、计算机使用和效率上有改进且成本更低，Simon Willison 已在 LLM 0.38 中加入支持。[3][6] Simon Willison 探索了为编码代理使用外部沙箱的新方法，以提高尝试本地模型时的安全性，避免错误或提示注入造成损害，并与 Prime Radiant 合作；他还完成了 Datasette Lite 的完整重写，借助服务工作者和 Pyodide 在浏览器中运行完整的服务器端 Datasette Python 应用，几乎与真实应用无异，可加载 SQLite 数据库、JSON 文件、CSV 文件或 SQL 脚本。[2][7] Vercel AI SDK 发布了 ai@7.0.176 和 ai@7.0.175 两个补丁版本，更新了相关依赖。[4][5]

全栈 / 运行时

Quad9 被迫从法国撤出，Cloudflare 将其视为煤矿中的金丝雀，凸显强制 DNS 级封锁的危险。[8] 强制公共解析器充当内容过滤器在技术上存在缺陷，并威胁开放互联网。[8]
