## 遗留技术债（不紧急，单独提交）

本轮跑检查时发现，都是既有问题，不是新引入的：

- `pnpm run format:check` 在 252 个文件上失败：`.prettierrc` 要求 `endOfLine: "lf"`，Windows 检出是 CRLF。修法是加 `.gitattributes`，但会产生全仓库 diff，要单独做。
- `pnpm lint` 有 2 个 `no-empty` 错误，在 `src/layouts/PostDetails.astro:365,378`。
- `pnpm run build` 离线必失败：`generateOgImages.tsx` 构建时从 `1001fonts.com` 拉 IBM Plex Mono。CI 有网所以线上正常。
- CI 只跑 `pnpm build`，不跑 lint 和 format。所以那两个失败不阻塞部署。
