## 1. 概念层次

- **AI（人工智能）**：最外层，让机器表现出智能行为的总体领域。
- **ML（机器学习）**：AI 的子集，从数据中学习规律而不是硬编码规则。
- **DL（深度学习）**：ML 的子集，使用多层神经网络。

```
AI  ⊃  ML  ⊃  DL
```

## 2. 学习范式

| 范式 | 数据 | 目标 | 典型场景 |
|---|---|---|---|
| 监督学习 Supervised | 带标签 | 预测标签 | 分类、回归 |
| 无监督学习 Unsupervised | 无标签 | 发现结构 | 聚类、降维 |
| 强化学习 RL | 环境反馈 | 最大化奖励 | 游戏、机器人 |
| 半监督 / 自监督 | 部分标签 / 自生成标签 | — | 预训练大模型 |

## 3. 常见任务类型

- **分类**：离散输出（垃圾邮件 / 正常邮件）
- **回归**：连续输出（房价预测）
- **聚类**：无标签分组（客户分群）
- **降维**：压缩特征（PCA）

## 4. 评估指标

| 指标 | 用途 | 记忆点 |
|---|---|---|
| Accuracy | 整体正确率 | 类别不平衡时不可靠 |
| Precision | 预测为正中真正比例 | 关注"误报" |
| Recall | 真实正中召回比例 | 关注"漏报" |
| F1 | Precision / Recall 调和平均 | 两者兼顾 |
| RMSE / MAE | 回归误差 | 越小越好 |
| AUC-ROC | 分类整体判别力 | 0.5 = 随机 |

## 5. 关键术语

- **特征（Feature）**：模型的输入变量
- **标签（Label）**：监督学习的目标输出
- **过拟合 / 欠拟合**：模型太复杂 / 太简单
- **训练 / 验证 / 测试集**：三者的分工
- **偏差-方差权衡（Bias-Variance）**

## 6. 易错点

- [ ] 混淆 Precision 和 Recall 的场景适用性
- [ ] 误以为无监督学习需要标签
- [ ] 把 DL 当成 AI 的同义词
