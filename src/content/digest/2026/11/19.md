## Angular

Angular 发布了 22.3.0 与 22.2.7。[1][2] 22.3.0 的编译器会在显式 ng-template 元素上报告未知属性绑定，并避免因无效 tracking 函数导致编译错误，有助于更早发现模板问题。[1] 22.2.7 的 core 在测试环境中抑制 hydration 警告，并在缺失 hydration 注释时抛出 NG0502 而非 TypeError，使水合失败更易定位。[2]

## 人工智能

Google 推出 Gemini 4 Neon 后，llm-gemini 发布 0.38；作者指出 Gemini 4 系列此前为 Hydrogen、Argon、Carbon（Argon 与 Carbon 同价，Hydrogen 为该价格的四分之三），Neon 使定价更加令人困惑。[3] Vercel AI SDK 发布 ai@7.0.177，为 steering 增加 interrupt 选项以取消尚未产生输出的模型调用，并在包内 `skills/ai-sdk` 提供 AI SDK skill，供 pnpm agent skills 使用。[4] datasette-arrows 0.1a0 发布，依托 Datasette 1.0a43 新增的插件流式导出能力；核心已支持流式 CSV 与 TSV，可在不全量载入内存的情况下导出大量数据。[5] Python 软件基金会启动年终筹款，用于支持 Python 开发与社区，包括维护 Python 知识产权、运营 PyPI、赞助核心开发者 sprint、支持社区活动并举办 PyCon US。[6] OpenAI 发表两篇文章：Dean Ball 讨论更强 AI 如何重塑社会以及人们如何保持对制度的控制；另一篇衡量编程智能体对 AI 研究的加速作用、表现仍不均衡，以及这对递归自我改进的含义。[7][8]

## 全栈 / 运行时

Bun 发布 v1.4.5，可通过官方安装脚本、npm 全局安装或 `bun upgrade` 升级，本版本感谢 3 位贡献者。[9] Cloudflare 新的 Workers AI Superintelligence 团队将 Clairic 与 Clairic-flash 以开源权重发布：Clairic 结束预览，Clairic-flash 加入 Workers AI，两者均为抽取模型。[10] Cloudflare 针对 Java4Shell（CVE-2026-114938）——OpenJDK Base64 解码器中可导致远程代码执行的严重内存损坏漏洞——为付费计划发布六条 WAF 托管规则（默认记录匹配请求），并提醒立即修补 Java 运行时。[11]
