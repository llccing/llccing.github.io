## Web / 框架

Vite 发布了 v8.3.8，并另有 v8.2.6、v8.2.5 两个版本放出 [1][2][3]。v8.3.8 修复了多项问题：构建时在 transform hook 的 meta 中保留 `magicString` 与 `ast`；bundled-dev 在 load 阶段发出内联 worker 所引用的资源；配置阶段对仅类型导入跳过 native loader 兼容性检查 [1]。v8.2.6 与 v8.2.5 的原始条目未列出具体变更，仅指向 changelog [2][3]。这些修复涉及构建元数据、worker 资源发出以及类型导入的配置校验，对使用 Vite 的项目值得关注。

## 人工智能

OpenAI 刊出与 Gilbert + Tobin 合伙人兼首席执行官 Sam Nickless 的对话，讨论该律所用 AI 重新思考法律业务 [4]；另称超过 2 万名退伍军人与转业军人已领取一年免费 ChatGPT Plus，用来为进入平民职业做准备 [5]。Vercel AI SDK 发布 ai@6.0.330 与 ai@5.0.289，均修复流式输出长数组时 CPU 占用过高的问题，改为增量解析并校验已完成的元素，而不是在每个文本块上反复处理整个累积数组；前者覆盖 `Output.array` 与 `streamObject`，后者针对 `streamObject` 的数组输出，并更新依赖 `@ai-sdk/gateway@2.0.180` [6][7]。Simon Willison 发布 llm-gemini 0.36：Gemini 4 Carbon 两周前仅向一部分网络防御者宣布，现已向其他人开放；材料称这是 Google 迄今最好的 Gemini，发布定价为输入 2 美元/百万、输出 10 美元/百万 [8]。他还让 Claude Code 编写了 Beep Locator，用散落在房间里的多台设备，对家中堆满未拆封纸箱的房间里间歇出现的神秘蜂鸣声做三角定位 [9]。
