## Angular

Angular 发布了 22.3.1 版本，包含动画和 common 模块的修复。[1] 动画修复避免了 createRenderer 中对 hostElement 的闭包，common 模块在相同路径导航时保留文本片段。这些修复提升了渲染稳定性和导航体验，值得开发者关注以保持应用可靠性。

## AI

Simon Willison 介绍了 sqlite3_rsync 这一 SQLite 数据库远程复制工具，该工具自 SQLite 3.47.0 起作为实验性功能加入，并在 3.50.0 中增强。[2] Vercel AI SDK 发布了 ai@7.0.183 和 ai@5.0.294 补丁版本，更新了相关依赖。[3][4] datasette-charts 推出 0.3a0 版本新增图表注释功能（支持线条、阴影区域和标签），0.2a1 版本则带来 UI 改进如折叠建议后图表仍可见。[5][6] OpenAI 分享了 Intentful 使用 dots 助手研究网站、构建提案并主动处理消息的案例，以及 iFood 在 15000 个仓库中扩展编码代理的实践。[7][8] 这些更新展示了 AI 工具、SDK 和实际应用的持续进展。

## 全栈 / 运行时

Cloudflare 推出 Search for Agents 功能，通过一个开关即可让网站被 AI 代理搜索，具备自动内容索引、可发现的搜索 API 和原生 HTTP QUERY 支持。[9] 该功能简化了站点对 AI 代理的可搜索性，值得关注以提升 AI 兼容性。
