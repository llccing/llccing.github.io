## Web / 框架

Vue.js 核心发布了 v3.6.0-rc.16 预发布版本。[1] 稳定版本详情见 CHANGELOG.md，预发布版本详情见 minor 分支的 CHANGELOG.md。[1]

## AI

Vercel AI SDK 发布 ai@7.0.179，gateway.experimental_realtime() 现支持通过 WebSocket 使用 Live 模型，可为 openai/gpt-live-1 和 openai/gpt-live-1.1 返回持续 Live 模型，连接 Gateway Live 路由并采用规范化 Live 协议（session-start、PCM16 音频、context-append、带最终用量的 session-close），也可通过参数指定 live 或 realtime 路由；此前这些模型 ID 会误开 realtime 路由并因 invalid_model 被拒绝。[2] 同期发布的 ai@7.0.178 修复 generateText 与 streamText 将 prepareStep 返回的 messages 数组原样传递的问题，现为每个步骤创建独立副本，使工具审批函数能区分不同模型响应的工具调用，并转发 streamText 中提供商执行工具结果的 preliminary 标志。[3] OpenAI 介绍对抗蒸馏的分层防护，结合模型训练、保障措施、检测和执行以防止能力提取。[4] Hebbia 测试 GPT-6 Astra 用于金融研究，预发布评估显示来源覆盖、引用相关性和呈现质量均有提升。[5]

## 全栈 / 运行时

Cloudflare WAF 已防护 ruby2shell（CVE-2026-132825），该漏洞可让攻击者在未登录情况下破坏默认 Rails 和 Sinatra 应用的内存，WAF 为包括免费计划在内的所有客户拦截此攻击，建议立即升级 Ruby 并用 WAF 覆盖空窗期。[6] 同时 WAF 防护 phpAfterShell 及其他关键 PHP 漏洞，phpAfterShell 是 PHP 默认会话处理器中的严重缺陷，可导致代码执行，WAF 为所有客户（含免费计划）提供拦截，并新增规则覆盖同一次发布中修复的其他 PHP 漏洞。[7]
