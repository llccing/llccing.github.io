## Angular

Angular 发布了 22.3.0-rc.0 和 22.2.6 版本，修复了渲染器中的内存泄漏问题，并改进了 HttpParams 以省略空数组。这些更改有助于减少内存占用并提升框架性能，值得关注因为 Angular 是主流前端框架。

## Web / 框架

Vue 发布了 v3.6.0-rc.15 版本，Vite 发布了 v8.3.7 版本。Vite 更新了 Rolldown 依赖，启用了更多 lint 规则，并改进了测试 tear downs。这些更新提升了构建工具的稳定性和开发体验，值得关注因为它们是现代 Web 开发的关键工具。

## AI

Google 发布了 Gemini Decisions API，这是一种新的决策模型 API，支持与 Jev 相同的三种问题类型，并使用相同的术语 "Noul"，值得关注因为它提供了类似 OpenAI GPT-6 的决策能力。AWS 发布了官方 aws-emulator，使用 Rust 编写并在三周内有近三万 commits，旨在让开发者无需付费 API 密钥就能测试本地服务。Simon Willison 改进了 tools.simonwillison.net 的标签浏览功能，使用 tree-sitter 分析工具代码。Vercel AI SDK 发布了 7.0.170 版本，修复了长时间流式处理中的 CPU 使用问题和取消操作。OpenAI 发布了关于 JioStar 在 500M 用户规模下使用 AI 发现的文章，以及面向护理人员的免费 ChatGPT 工作坊。这些更新反映了 AI 生态系统的活跃发展和实际应用。

## 全栈 / 运行时

Node.js 发布了多个 LTS 版本，包括 26.13.1、24.22.3 和 22.23.5，这些是安全更新，修复了 http2 流处理和 tls 协商相关的高危漏洞。Cloudflare 介绍了 QuePaxa，一种新的共识算法，用于构建实验性共识服务。这些更新提高了 Node.js 的安全性和 Cloudflare 服务的稳定性，值得关注因为它们涉及关键基础设施。
