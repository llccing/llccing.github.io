## 人工智能

Simon Willison 受 Hacker News 上关于 Paul Ford 文章的评论启发，用 Three.js 做了一个海蛞蝓主题的法贝热彩蛋（77KB），并让常规 Claude Chat 中的 Opus 5.5 Medium 将其移植到 Vanilla [1]。他表示自己项目里多数改动已变成由 Claude Code 或 Codex 代开的 PR，PR 是工作单元，但代理写的描述过于准确、全面，因此主张用 details 与 summary 标签把这类 slop PR 描述折叠隐藏 [2]。他还研究了为 SQLite 编写 parse_number() 扩展时 C 与 Rust 的差异：该函数把 -$1,234.56、12.5% 等字符串转成可汇总、可排序的数值，同样通过 Opus 5.5 完成，以观察两种语言实现扩展的难易 [5]。Vercel AI SDK 发布补丁 ai@6.0.326 与 ai@7.0.166，分别更新依赖 @ai-sdk/gateway@3.0.232 与 @ai-sdk/gateway@4.0.139，6.x 与 7.x 两条线仍在同步维护 [3][4]。OpenAI 推出 National Community Compact 与 Compute Campus Policy Blueprint，用以保护地方资源、创造就业并指导负责任的 AI 基础设施建设 [6]；Flipsnack 将 ChatGPT Ads 活动聚焦于吸引用户试用产品，提升了注册量并降低了单次注册成本 [7]。
