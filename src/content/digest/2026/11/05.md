## 网页 / 框架

Vite 发布了 v8.3.6 版本，修复了等待重叠插件容器关闭调用、构建时解析带有查询的动态导入以收集 CSS 依赖以及在分块导入映射哈希签名中使用稳定模块 ID 的问题。[1] 这些修复提高了构建过程的稳定性。

## 人工智能

Vercel AI SDK 发布了 ai@7.0.163，修复了从字节检测下载音频类型、尊重记录输入输出传递遥测事件以及在流式 Google 响应中保留文本和函数调用顺序的补丁。[2] 另一个版本 ai@6.0.323 更新了依赖。[3] Simon Willison 发布了 datasette-llm 0.1a10 以修复代理演示站点中限制 LLM 模型的 bug，datasette-apps 0.3a0 支持在 Datasette 中托管编辑自定义 HTML 应用并通过代理聊天标签应用，datasette-agent 0.5a0 引入了面板功能让代理聊天坐在 Datasette 页面旁。[4][7][8] OpenAI 宣布将收购 Pierre Computer Company 以扩展 Codex 工具，并构建自主管道发现了 948 个 Linux 内核本地权限升级漏洞。[5][6] 这些更新值得关注，因为它们改进了 AI 工具的检测、集成和安全功能。

## 全栈 / 运行时

Cloudflare 发布了关于个人代理的新博客，提供了对个人 AI 代理的可见性和控制，帮助站点所有者管理代理访问。[9] 个人 AI 代理改变了用户与网页的交互，模糊了自动化和人类流量的界限。此功能值得关注，因为它为网站提供了更好的管理工具。
