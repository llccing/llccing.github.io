## 人工智能

Graham Dumpleton 在启动 mod_wsgi 二十年后，推出由 AI 辅助开发的 Rust 服务器 Muru，目标是为开发与生产环境提供运行 ASGI 和 WSGI Python 应用的最佳工具，并像此前 wrapture 项目一样持续公开极为详尽的开发过程。[1] 工具链方面，Vercel AI SDK 发布 ai@5.0.292 补丁，更新依赖并将 @ai-sdk/gateway 升至 2.0.183；llm-gemini 0.38.1 则补上此前遗漏：Gemini 4 Carbon 仅支持 low、medium、high 推理级别，而 Hydrogen 与 Neon 额外支持 xhigh，且 Hydrogen 上的 xhigh 会带来显著差异。[2][3] OpenAI 介绍了 MedChemBench，用于评估模型在早期药物发现中解读分子结构、依据实验证据推理并筛选化合物的能力，同时展示 Codex Security Plugin 从上手到审阅结果的工作流。[4][5]
