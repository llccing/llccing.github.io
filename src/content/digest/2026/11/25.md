## Web / 框架

Vite 发布了 v8.4.0-beta.2 版本。[1] 该版本新增了在 hook 错误中添加插件名称以及在模块 hook 错误中添加插件名称的功能，并修复了服务器启动失败时未能关闭服务器的问题。这些改动有助于更准确地定位插件相关错误，同时提升开发服务器启动过程的稳定性，对依赖 Vite 的前端开发流程具有直接帮助。

## 人工智能

Simon Willison 在 AI Engineer Code Summit 上发表主题演讲，围绕过去十二个月 LLM 与编码代理能力出现的三个重要拐点展开，并在后续博文中进一步深入探讨该主题。[2] GPT-6.2 Astra 仅用最少提示就在 22 分钟内自主识别出耶鲁大学 Beinecke 图书馆一本 1808 年匿名素描本的创作者，展示了其在历史研究中的实际应用。[3] OpenAI 的 GPT-6 模型展现出内在蛋白质设计能力，能够通过推理和代码设计蛋白质结构和序列，实验室测试在五个靶点上发现了结合证据。[4] 两名业余天文学家使用 Codex 和 Astra 在 NASA Kepler 和 TESS 太空望远镜的公开数据中搜寻潜在系外行星。[5] Ladybird 浏览器发布了首个 alpha 版本，这是一个 2026 年全新的浏览器项目，自行实现了 HTML 解析、CSS 引擎、布局、JavaScript 乃至 WebAssembly 等大部分关键组件。[6]
