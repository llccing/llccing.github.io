## AI

Simon Willison 发布 datasette-charts 0.2a0，该 Datasette 图表插件已与 Datasette Agent 打通，用户可在对话中请求生成图表，并复用同一套图表建议与生成工具 [1]；datasette-agent 0.7a1 则改进了聊天会话 iframe 侧边栏的 fragment hash 导航，以便与会在交互中更新 hash 的其他插件更深集成 [2]。中国 AI 实验室 Z.ai 推出 GLM-5.4，这是其首个采用 Loop Transformer 的模型：一组权重共享层会多次迭代、精炼上一轮隐藏状态，从而在不增加参数量的情况下获得更深网络 [3]。OpenAI 与 Cisco 发布面向 Linux 的开源运行时 Shirudo，帮助团队在滚动打补丁时保护正在运行的系统 [4]。OpenAI 的 Stacey Wang、Craig Bruney 与 LECG 的 Mary O’Carroll、Cooley 的 Richard Segal 探讨了 AI 如何帮助企业内部法务连接业务上下文、构建可复用工作流并更好利用外部律师 [7]。Vercel AI SDK 发布 ai@7.0.181，新增每次调用的 onWarning 回调、在 generateText 与 streamText 结果中加入 stoppedBy 以说明工具循环停止原因，并在提取遥测中剥离文本与文件部件的 provider options；ai@7.0.180 则更新了 @ai-sdk/gateway 依赖 [5][6]。

## 全栈 / 运行时

JEP 545（Faster Startup and Warmup with ZGC）已合入 JDK 28，将堆内存准备从启动路径移到并发工作线程；ZGC 会在堆扩展时预触碰内存，并在 Linux 6.1 及更高版本把小页升级为大页 [8]。该 JEP 给出的 38% 启动加速与 90% 预热提升依赖于 2 MB 初始堆，而这需要默认关闭的 JEP 546 自适应堆大小标志 [8]。本周 Java 动态还包括 Java4Shell 远程代码执行漏洞、Oracle CSPUs、计划进入 JDK 28 的 Lazy Constants，以及 Azul Payara 的 2026 年 11 月版、Java Operator SDK、LangChain4j 与 Micrometer 的小版本、Liberica JDK 与 Helidon 的维护版本，和 Hibernate Reactive 的第二个候选发布 [9]。Cloudflare 介绍了其内部测试框架如何被扩展，供团队为网络协议构建测试工具，并实际用于 DNS 探测 [10]。
