## Angular

Angular 21.2.26 与 20.3.35 均包含同一项修复：仅编译降级组件的模板内容。[1][2] 该修复同时进入 21.x 与 20.x 两条发布线，说明降级组件的模板编译范围问题已在多个维护版本中处理，相关项目可据此评估升级。

## 人工智能

Simon Willison 介绍了 Colsto 的 OSINT 演示：从视频音轨中几乎难以察觉的飞机背景噪声提取多普勒曲线，再与 ADS-B 数据交叉比对，依据速度、距离和不同航班之间的间隔定位拍摄地点。[3] 其十月赞助者通讯涵盖 vibe 游戏开发拐点、漏洞态势升温、LLM 发布、每月 100 美元以上订阅的 API 额度、当前所用工具及软件发布；同期推出的 llm 0.37 汇集约两个月的功能与修复，新增 gpt-6.1-sol、gpt-6.1-terra，并加入 llm openai endpoint add 命令以便配置 OpenAI 兼容端点。[4][7] Vercel AI SDK 的 ai@7.0.162 在校验工具审批续跑时恢复服务端定义的工具元数据、动态状态与标题，使审批策略获得与新模型调用相同的工具定义字段，并为持久化 WorkflowAgent 运行提供包含提示、最终输出、步骤与工具的单一遥测操作；ai@5.0.285 则修复 DefaultGeneratedFile 以及提示数据校验与转换中对跨 realm 的 Uint8Array 与 ArrayBuffer 的支持。[5][6] OpenAI 提高安全漏洞赏金，并引入报告质量、忠诚度与优先活动奖金；同时正与 Cathedral Systems 筹备下一轮内部安全冲刺，以 AI 测试并加固自身防御。[8][9]

## 全栈 / 运行时

InfoQ 的 Java 新闻周报（2026 年 10 月 26 日）汇总了多项版本动态：TornadoVM 8.0 正式发布；JNoSQL、Endive、JBang、JReleaser 与 LangChain4j 发布点版本；JobRunr 发布维护版本；Hibernate ORM 与 Hibernate Reactive 发布 beta；并介绍了 Quarkus Almanac。[10] 上述更新集中反映 Java 生态在运行时与周边工具链上的近期进展，适合跟进全栈与运行时相关变化。
