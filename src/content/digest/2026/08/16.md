## 人工智能

Simon Willison 发布了 CORS Chat，用于测试在 LM Studio 上运行的 Qwen 3.8 27B（覆盖 M5 MacBook Pro 与 NVIDIA DGX Spark），提供兼容 OpenAI-Responses 的聊天 Web UI，支持浏览器内持久化对话并以 JSON 导出，还能在 token 仍在流式输出时渐进渲染 SVG 图像；该工具已在开启 `--cors` 的 LM Studio 与 OpenRouter 上验证可用 [1]。Vercel AI SDK 同步放出 ai@7.0.66 与 ai@6.0.255 补丁：两者均将 chat status 保持为 submitted 直至响应内容开始流式输出，并修复推断 `Output` 类型的导出值声明生成问题 [3][4]。ai@6.0.255 还进一步优化 `readUIMessageStream`，避免反复克隆累积文本，同时为可变嵌套值保留独立快照 [4]。
