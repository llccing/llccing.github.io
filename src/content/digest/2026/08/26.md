## AI

EVE Online 已开始向 Python 3 迁移。该项目自 2003 年上线起一直运行 Stackless Python，上次重大升级是 16 年前（2010 年）升至 Stackless Python 2.7，二十多年来被视为 Python 大规模应用的案例 [1]。OpenAI CFO Sarah Friar 说明芯片、算力、模型与产品上的进展如何叠加，从而以更大规模、更低成本提供更有用的智能 [2]。OpenAI 自研推理芯片 Jalapeño 公布首批结果，材料称其在现代模型上实现更快、更省电的推理，以及更高吞吐与更低延迟，并展示业界领先的速度与效率 [3]。Vercel AI SDK 发布 ai@7.0.79：在另一路合并 UI 消息流结束某一步时保留仍处于活动状态的文本与推理片段，并使工作流流规范化与显式 part 结束分块对齐；`experimental_startTextBatch` 支持 `webhookUrl`，由 gateway 经批量 `callbackUrl` 注册并导出异步任务元数据，直连 Anthropic 与 OpenAI 批量提供方在传入该选项时给出不支持警告；另有在提供方省略 finishReas 时解析结构化 `generateText` 输出等补丁 [4]。同系列 ai@6.0.266 则在复验后的工具输入无效时，以模型可见的工具错误继续已批准的 `generateText`/`streamText` 回合，并避免已中止、出错或取消的 `streamText` 经 abort 清理监听器残留每次调用的状态 [5]。

## 全栈 / 运行时

InfoQ 汇总了 2026 年 8 月 17 日当周 Java 动态，覆盖 JDK、OpenJDK JEP、Jakarta EE、BellSoft、Helidon、Micrometer 与 Apache Tika [6]。JDK 27 发布首个候选版本（RC1），JEP 541 与 JEP 540 被定为 JDK 28 目标，标志着下一两个版本的发布节奏已可见 [6]。生态方面，Apache Tika 4.0 达到 GA，Helidon 发布维护版本，Micrometer Metrics 1.18 与 Micrometer Tracing 1.8 迎来首个里程碑，同时还有 Jakarta EE 12 进展以及 BellSoft 关键安全补丁更新 [6]。
