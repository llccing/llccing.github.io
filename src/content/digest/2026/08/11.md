## AI

Meta 推出全新 30B 开源权重模型 Muse Glimmer，采用干净的 Apache 2.0 许可，面向端到端智能体任务完成与可靠工具使用做了优化，并在 DeepSearch QA、MCP-Atlas、τ-Bench、SWE-Bench 等全任务基准上取得较强成功率 [1]。Vercel AI SDK 发布了 ai@6.0.247 与 ai@7.0.59 两个补丁版本，分别更新了 provider-utils 与 gateway 等依赖 [2][3]。OpenAI CFO Sarah Friar 分享了建设 AI 原生财务职能的五项经验，涵盖自动预测、更强管控与 AI ROI 等 [4]；OpenAI 还致信得克萨斯州州长 Abbott，表明对当地负责任 AI 基础设施发展的承诺 [5]。

## 全栈 / 运行时

Cloudflare 汇总了 Agents Week 期间的全部发布，从 Wallets 到 Radar 等多项能力均有公告 [6]。Cloudflare for Government 获得 FedRAMP Class D (High) 认证，并宣布将继续推进 DoD IL4 授权，把安全、性能与开发者产品带向公共部门 [8]。Java 方面，JEP 401 已集成进 JDK 28，作为 Project Valhalla 首个预览引入 value objects：字段为 final、相等性语义改变，并收紧构造与同步规则，预览默认关闭且需特定编译与运行配置 [7]。同期 Java 动态还包括面向 JDK 28 的 JEP 535（Shenandoah GC 默认分代模式）、A2A Java SDK / Apache Camel / Gradle 点版本、GlassFish 维护版、Groovy 8.0 第五个里程碑，以及 JetBrains TeamCity CVE 后续进展 [9]。
