## Angular

Angular 同时放出多条版本线更新，包括下一代预览 22.2.0-next.3、22.1.3，以及仍在维护的 21.2.21 与 20.3.29。[1][2][3][4] 新预览与多个已发布大版本的补丁并行出现，说明框架仍在同步推进下一代特性验证和既有版本维护，升级路径需要对照自身所在主版本跟进。

## 人工智能

OpenAI 宣布为前沿模型提供零数据保留，将 ChatGPT 广告扩展至欧洲，并与 Replit 合作、借助 GPT-5.6 Luna 扩大软件创作的可及范围。[7][11][12] 治理与教育方面，OpenAI 提出加强国家安全领域的民主监督，同时与 CodeAI 合作帮助学生建立 AI 素养、批判性思考并负责任地使用和塑造 AI；面对网络关键能力时代，它还强调强化对前沿模型的监控、对齐与安全，以新的保障措施引导开发节奏。[14][16][17] Vercel AI SDK 连续发布 ai@7.0.69、ai@7.0.70，并同步更新仍在维护的 ai@6.0.259 与 ai@5.0.240。[6][8][9][10] Simon Willison 撰文讨论概念完整性与代码行数，并指出 Mojo 现已开源；他还研究将 smolmachines / smolvm 作为不受信任 Python 与 JavaScript 的沙箱，限制内存和 CPU 时间以防死循环，且无网络访问，该项探索由运行在 Claude Code for web 中的 Claude Fable 5 完成。[5][13][15]

## 全栈 / 运行时

Cloudflare 再次审视 Workers 上的远程 Spectre 攻击，并跟踪 RFC 9234 BGP Role 模型的采用情况。[18][19] Java 方面，JEP 540 被提议纳入 JDK 28，将提供一套简易 JSON API；同期综述还涉及 GlassFish、Jakarta EE、JNoSQL、Open Liberty、LangChain4j 等动态。[20][21] Project Valhalla 迎来首个预览：已并入 JDK 28 的 JEP 401 引入 value objects，字段为 final，相等性检查行为有变，构造与同步规则更严格，旨在提升效率并降低内存分配成本；该预览默认关闭，编译与运行时需额外配置。[22] 2026 年 8 月 3 日的 Java 周报还提到，面向 JDK 28 的 JEP 535 将把 Shenandoah GC 的分代模式设为默认，并有 A2A Java SDK、Apache Camel、Gradle 的点版本，GlassFish 维护版、Groovy 8.0 第五个里程碑，以及对 JetBrains TeamCity CVE 的后续跟进。[23]
