## Angular

Angular 发布了 22.2.0-next.3、22.1.3、21.2.21 与 20.3.29 [1][2][4][3]。更新同时覆盖 20、21、22 三条版本线，并包含 22.2 的 next 预发布，说明稳定修复与下一小版本迭代仍在并行推进。

## AI

OpenAI 宣布为前沿模型提供零数据保留 [7]，将 ChatGPT 广告扩展至欧洲 [11]，推出面向青少年、强调学习与保护的 ChatGPT [18]，并与 Replit 借助 GPT-5.6 Luna 扩大软件创作准入 [12]；同期还发布了加强国家安全民主监督、在网络关键能力时代把握模型开发节奏，以及与 CodeAI 合作等消息 [14][17][16]。企业与政策方面，Asana 用 Codex 在两周内清理了五年工程工作 [19]，NVIDIA 团队用 ChatGPT Work 减少手工任务、连接快速变化的信号并在全球规模化成功工作流 [20]；OpenAI 还资助 14 个独立项目，探索智能时代的新政策构想，以扩大经济机会并增强社会韧性 [21]。Vercel AI SDK 发布 ai@7.0.69 与 ai@7.0.70，并同步更新 ai@6.0.259、ai@5.0.240 [6][8][9][10]。Simon Willison 讨论了概念完整性与代码行数统计 [5]，指出 Mojo 现已开源 [13]，并介绍 smolmachines / smolvm 作为不可信 Python 与 JavaScript 的沙箱 [15]。

## 全栈 / 运行时

Cloudflare 发表两篇博文：一是重新审视针对 Cloudflare Workers 的远程 Spectre 攻击 [22]，二是跟踪 RFC 9234 中 BGP Role 模型的采用情况 [23]。Java 方面，JEP 540 被提议纳入 JDK 28，将提供简易 JSON API [24][25]；Project Valhalla 迎来首个预览，JEP 401 重新定义了 Java 对象的 == [26]。同期 Java 新闻还涉及 Shenandoah GC、TeamCity CVE、A2A Java SDK、Camel、Gradle、GlassFish、Groovy、Jakarta EE、JNoSQL、Open Liberty 与 LangChain4j 等 [25][27]。
