## Angular

Angular 同步放出多条版本线更新：预览版 22.2.0-next.3 [1]、22.1 线补丁 22.1.3 [2]，以及仍在维护的 21.2.21 [4] 与 20.3.29 [3]。多条大版本并行发版，说明项目仍在同时支撑新旧主干。材料未给出各版本的具体变更内容。

## 人工智能

OpenAI 集中公布多项产品与政策：为前沿模型提供零数据保留 [7]；ChatGPT 广告扩展至欧洲 [11]；推出面向青少年的 ChatGPT for Teens，强调学习、批判性思维与更强的内置保护、健康使用功能及家长控制 [18]；Replit 借助 GPT-5.6 Luna 扩大软件创作准入 [12]；并与 CodeAI 合作，为第一代 AI 世代做准备 [16]。治理与节奏方面，OpenAI 还提到加强国家安全领域的民主监督 [14]，以及在具备网络关键能力的时代控制模型开发节奏 [17]。落地案例上，Asana 用 Codex 在两周内替换过时测试系统，完成原预计五年的工作，花费约 1.2 万美元 [19]。Vercel AI SDK 连续发布 ai@7.0.69、ai@7.0.70，并同步更新 6.x 与 5.x 线 [6][8][9][10]。Simon Willison 则讨论概念完整性与代码行数统计 [5]，称 Mojo 现已开源 [13]，并介绍 smolmachines / smolvm 作为不可信 Python 与 JavaScript 的沙箱 [15]。

## 全栈 / 运行时

Cloudflare 重新审视针对 Workers 的远程 Spectre 攻击 [20]，并跟踪 RFC 9234 所定义 BGP Role 模型的采用情况 [21]。Java 方面，JEP 540（Simple JSON API）被提议以 JDK 28 为靶向版本 [22]；Project Valhalla 迎来首个预览，JEP 401 重新定义了 Java 对象的 `==` 语义 [24]。InfoQ 两期新闻综述还汇总了 GlassFish、Jakarta EE、JNoSQL、Open Liberty、LangChain4j，以及 Shenandoah GC、TeamCity CVE、A2A Java SDK、Camel、Gradle、Groovy 等进展 [23][25]。
