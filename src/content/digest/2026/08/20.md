## 全栈 / 运行时

JEP 540 Simple JSON API 已进入 JDK 28 的 Target 状态，提供无需外部依赖的紧凑 JSON 解析与生成 API，采用不可变值层次结构，支持简单遍历与转换并强制严格语法，孵化期反馈将影响后续发展 [7]。同期 Java 周报还涵盖 Jakarta EE 12 进展、Open Liberty 2026 年 8 月版、LangChain4j 点版本，以及 Eclipse JNoSQL 与 GraalVM Native Build tools 的维护版本 [8]。GlassFish 9.0 发布第三个里程碑，Groovy 6.0 发布第二个 beta [8]。
