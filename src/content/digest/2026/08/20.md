## Angular

Angular 同时放出多条版本线更新：22.2.0-next.3、22.1.3、20.3.29 与 21.2.21 [1][2][3][4]。22.2.0-next.3 与 22.1.3 均修复 animations 用 `Object.hasOwn` 检测对象类型 trigger 值，以及 common 中 `KeyValuePipe.transform()` 保留字面量键联合类型 [1][2]。20.3.29 与 21.2.21 则在 platform-browser 中禁止 Meta 使用事件处理属性 [3][4]。同一批修正落在预览版与多条稳定线上，使用这些版本的项目需要核对是否已包含对应修复。

## AI

Simon Willison 在 Talking Postgres 播客中与 Claire Giordano 讨论「AI 如何改变软件开发」，并继续论证在某些情况下以代码行数作为生产力指标是合理的 [5]。Vercel AI SDK 发布 ai@7.0.70、ai@7.0.69、ai@6.0.259 与 ai@5.0.240：7.0.70 改进客户端工具审批、`streamObject` 错误处理、未完成工具调用过滤和 WorkflowAgent 重试行为 [6]，较早的补丁则更新了 gateway 依赖 [7][8][9]。Mojo 在发布 1.0 后兑现了自 2023 年 5 月以来的开源承诺，以 Apache 2 许可证公开编译器与工具链；该语言最初目标是成为 Python 超集，使现有 Python 代码可以使用 [10]。OpenAI 重申对符合条件的 API 客户提供前沿模型零数据保留，并预览 Private Safety Processing [11]；同时将 ChatGPT Ads 扩展到 31 个欧洲市场 [12]，并发起加强国家安全领域 AI 民主监督的倡议 [13]。Replit 还推出由 GPT-5.6 Luna 驱动的 Free Mode，让用户不必担心 token 成本即可把想法做成可运行软件 [14]。

## 全栈 / 运行时

Cloudflare 回顾 2024 与 2025 年对 Workers 远程 Spectre 攻击的再评估，披露 Spectre gadgets、远程计时器、实现共址等新攻击原语，并说明新防御进一步加固了 Workers [15]。另一篇跟踪 RFC 9234 落地：该规范让路由器借助 BGP Roles 与 Only to Customer（OTC）属性自行拒绝路由泄漏；实测发现有两家 Tier 1 网络意外剥离了 OTC [16]。前者直接关系到边缘隔离是否仍扛得住远程侧信道，后者则暴露骨干网上 OTC 部署并不完整。JEP 540 Simple JSON API 已进入 JDK 28 的 Target 状态，提供无需外部依赖的紧凑 JSON 解析与生成 API，采用不可变值层次结构，支持简单遍历与转换并强制严格语法 [17]。同期 Java 周报还涵盖 Jakarta EE 12、Open Liberty、LangChain4j、Eclipse JNoSQL 和 GraalVM Native Build tools 的更新，GlassFish 9.0 发布第三个里程碑，Groovy 6.0 发布第二个 beta [18]。
