## Angular

Angular 同时放出多条版本线更新：22.2.0-next.3、22.1.3、20.3.29 与 21.2.21 [1][2][3][4]。22.2.0-next.3 与 22.1.3 均修复 animations 用 `Object.hasOwn` 检测对象类型 trigger 值，以及 common 中 `KeyValuePipe.transform()` 保留字面量键联合类型 [1][2]。20.3.29 与 21.2.21 则在 platform-browser 中禁止 Meta 使用事件处理属性 [3][4]。同一批修正落在预览版与多条稳定线上，使用这些版本的项目需要核对是否已包含对应修复。

## AI

Vercel AI SDK 发布 ai@7.0.70：在客户端工具审批场景下，即使提供商执行的工具仍有延迟结果，也会停止多步文本生成；`streamObject` 在提供商流出错时拒绝结果 Promise 并报告失败完成；启用 `ignoreIncompleteToolCalls` 时过滤初步工具输出；模型调用以不安全结束原因终止时阻止自动执行工具；WorkflowAgent 重试模型调用步骤时清除部分 UI 消息片段，并更新 `@ai-sdk/provider-utils` [5]。同系列还发布 ai@5.0.240，主要更新 `@ai-sdk/gateway` 依赖 [7]。OpenAI 重申对符合条件的 API 客户提供前沿模型零数据保留，并预览 Private Safety Processing，以便在不牺牲数据隐私的前提下做高级 AI 安全处理 [6]。Replit 推出由 GPT-5.6 Luna 驱动的 Free Mode，让用户不必担心 token 成本即可把想法做成可运行软件 [8]。

## 全栈 / 运行时

Cloudflare 回顾 2024 与 2025 年对 Workers 远程 Spectre 攻击的再评估，披露 Spectre gadgets、远程计时器、实现共址等新攻击原语，并说明新防御进一步加固了 Workers [9]。另一篇跟踪 RFC 9234 落地：该规范让路由器借助 BGP Roles 与 Only to Customer（OTC）属性自行拒绝路由泄漏；实测发现有两家 Tier 1 网络意外剥离了 OTC [10]。前者直接关系到边缘隔离是否仍扛得住远程侧信道，后者则暴露骨干网上 OTC 部署并不完整。
