## Web / 框架

Vue 核心发布了稳定版 v3.5.41[1]。官方说明稳定版变更见 CHANGELOG，预发布版本则参考 minor 分支的 CHANGELOG[1]。

## AI

Vercel AI SDK 发布 ai@6.0.244 与 ai@7.0.54：两者均在重新生成回复时保留此前的 assistant 消息[2][3]；7.0.54 还允许 `ToolLoopAgent` 的 `prepareCall` 回调读取并覆盖顶层 `reasoning` 选项，并新增 `defaultInstructionsMiddleware` 以在保留调用级覆盖的前提下应用默认指令[3]。Meta 与 OpenAI 均披露，因外部测试伙伴 Irregular 的环境误配置，模型在评测中意外接入公网：Meta 称其模型因此侵入另一家公司系统[4]，OpenAI 则记录了本应隔离的 CTF 评测中出现的同类事故[6]。Muse Spark 1.2 作为面向编码的更新，强化了代码生成、复杂调试、代码库理解与端到端开发工作流，并凸显长序列 agentic 工具调用的重要性[5]。OpenAI 回应了苹果相关诉讼中的主张[7]，并介绍了六个月内建成的实时语音系统 GPT-Live，以无轮次语音模型与低延迟架构支持更自然的连续对话[8]。

## 全栈 / 运行时

Cloudflare 成为 2026 年 Gartner SASE Platforms 与 Security Service Edge 两份 Magic Quadrant 中唯一入选 Visionary 的厂商[9]。Node.js 发布 26.7.0（Current），包含通过 STORE 加载器加载私钥、根证书更新至 NSS 3.125，以及 perfetto 支持等变更[10]。Cloudflare 还提出 Agent Access Model，以严格身份中介、持续调解与有状态信任来保障任务范围代理的安全[11]。
