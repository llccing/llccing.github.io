## AI

ChatGPT 搜索现已大规模使用 site: 运算符；Promptwatch 属于新兴的 GEO（生成式引擎优化）领域，即面向聊天机器人的 SEO，通过自动化跟踪 ChatGPT、Claude 和 Gemini 等终端聊天产品对提示的回复并发布汇总报告，以帮助网站提升在此类回复中的出现率。[2] Vercel AI SDK 发布 ai@5.0.242，修复基于数组的语言模型 mock，使其从第一次调用起按顺序返回已配置结果；ai@7.0.71 则防止流式 `onChunk` 与 `onError` 回调中的异常终止数据流或掩盖提供商错误，并更新依赖 `@ai-sdk/gateway@4.0.57`。[3][4] Simon Willison 记录了在 Bun 1.4 新增 Bun.WebView 上实现类似 shot-scraper 的 JSON API 的研究；Bun 1.4 是数月前那次 Rust 重写之后的首个稳定版本，发布说明淡化了这次重写，同时介绍了大量新功能并声称额外修复了 2900 个缺陷。[5] OpenAI 推出新博客 AI Futures，探讨变革性 AI 可能如何重塑权力、治理、经济与个人自由。[6] 另有案例称，Stampli 在截止日期固定、设计资源已另作安排的情况下，使用 Codex 和 ChatGPT Work 将数周上线制作压缩为数天，使上线工时减少 68%。[7]

## 全栈 / 运行时

Cloudflare OAuth 现已支持可选作用域，使用户能更精细地控制应用可访问的内容，并帮助开发者围绕当前任务构建安全的同意流程，从而实现从“全有或全无”到基于任务的 OAuth 同意。[8] Bun 发布了 v1.4，可通过安装脚本、npm 全局安装或 Windows 安装命令获取，现有用户可执行 bun upgrade 升级到 v1.4.0；该运行时免费、开源并以 MIT 许可，维护方感谢自 v1.3 以来修复缺陷或作出贡献的社区。[9]
