## AI

Vercel AI SDK 发布了 ai@6.0.241 与 ai@5.0.226 两个补丁版本，分别更新了对应的 @ai-sdk/gateway 依赖 [1][2]。OpenAI 介绍了用于响应式语音交互的实时系统 GPT-Live，采用无轮次语音模型与低延迟架构，以支持更连续、自然的对话 [4]；并分享了在数学与理论计算机科学若干长期开放问题上的新进展，涵盖几何、密码学与复杂性等领域 [7]。Simon Willison 指出，LLM 使审查与修改开源开发工具变得更可行 [3]；同时发布了 condense-json 1.0，用于按替换规则压缩 JSON 中的重复字符串 [5]；并汇总了近期关于 AI 发展的公开信，其中包括由微软推动、多家公司签署的 Open Weights and American AI Leadership [6]。

## 全栈 / 运行时

Node.js 发布了 Current 版本 26.6.0，包含 ffi 的 `getCurrentEventLoop`、test_runner 的 `context.log()` 与 `test:log` 事件等变更 [9]；LTS 版本 24.19.0 'Krypton' 则实现了 `blob.textStream()`，并更新 OpenSSL 构建配置以支持压缩等 [10]。Cloudflare 推出 @cloudflare/computer，在高效 isolate 与完整 Linux 容器之间动态编排，为 agent 提供独立运行环境 [11]；Workers 与 Containers 现支持经 Spectrum 的入站 TCP 连接，并可在 Workers 中运行全双工 gRPC 或使用 gRPC 到 gRPC-web 的自动转换 [12]。Java 方面，InfoQ 周报涵盖面向 JDK 28 的 OpenJDK JEP、GPULlama3.java 1.0、Micronaut/Quarkus/JobRunr 点版本、Maven 4.0 第六个候选版以及 Jakarta Agentic AI 1.0 首个里程碑 [8]；Embabel Agent Framework 也达到 1.0，基于 Spring AI，支持以类型化领域对象定义 agent，并组合规划与预定义状态机 [13]。
