## Angular

Angular 同时放出多条版本线更新：22.2.0-next.4、22.1.4、21.2.22 与 20.3.30。[1][2][3][4]
22.2.0-next.4 与 22.1.4 的 common 包均修复了原型成员冲突，并在数字格式化中改用 locale 的 NaN 符号。[1][2]
21.2.22 与 20.3.30 的 platform-server 则避免在 URL 解析时剥离 Unicode 空白，并把 domino 更新到最新版本。[3][4]
同类修复沿预发布、当前与更早稳定线同步落地，数字格式化与服务端 URL 解析相关问题值得跟进。

## Web / 框架

Vue 核心发布了 v3.5.42。[5]
材料未列出具体变更，仅说明稳定版与预发布版分别见对应 CHANGELOG。[5]

## AI

OpenAI 宣布扩大在巴西的布局，加深与开发者、企业与社区的互动，以支持当地 AI 采用。[6]
ChatGPT for Teachers 扩展到 55 个美国学区，为超过 10 万名教育工作者和员工提供安全 AI 工具、培训与支持。[10]
Qwen 放出开源权重模型 Qwen3.8-Flash-Next：多模态 MoE，也是 Qwen4 所用架构的早期预览；规模为 125B tokens、仅 6B 激活。Simon Willison 在 DGX Spark 上用 Unsloth 量化模型试用，并提到 72.5GB 的 UD-IQ1_S 版本。[7]
Vercel AI SDK 的 ai@5.0.248 按保守 UTF-8 字节预算（由聚合 token 上限推导）拆分 OpenAI 与 Azure OpenAI 的 embedding 请求，同时仍受输入条数限制。[8]
ai@7.0.83 则按当前输入/输出 schema 校验持久化的 typed tool calls（不兼容的空值、错误输入及不可用工具的终端历史改为动态 tool parts）、在工具审批拒绝进入 `output-denied` 后允许对话自动继续、为 UI message stream 结束回调增加 operation-level outcomes，并修复 stitchable stream 在内部流注册前被取消的问题。[9]

## 全栈 / 运行时

Node.js 于 2026-08-26 发布 Current 线 26.8.0、带外补丁 26.8.1，以及 LTS 24.20.0（Krypton）。[11][12][13]
26.8.1 用于修正 `node --version` 误报 alpha 版本，并回退了意外的 alpha 标记。[11]
26.8.0 的显著变化包括为 benchmark 的 compare.js 增加 `--analyze` 模式、将根证书更新至 NSS 3.126，以及在 Cipher/Decipher API 中启用 SIV 与 GCM-SIV。[12]
24.20.0 则为 AsyncLocalStorage 增加 `using` scopes、为 buffer 增加 `end` 参数，并将根证书更新至 NSS 3.125。[13]
