## AI

Qwen 3.8 27B 在 Artificial Analysis Intelligence Index 上取得 52 分，与 GPT-5.6 Luna (max) 同分，仅比 GLM-5.2 (max) 和 DeepSeek V4 Pro 0813 (max) 低一分；对比模型中 GLM 达 753B、DeepSeek 为 1.6B 参数，Luna 规模未知但远大于 27B，因此该 27B 模型表现令人惊叹 [1]。404 Media 用 AirTag 追踪一批约千册稀有书籍的货运，终点落在亚马逊 AI 训练设施，印证了书商此前收到大量价格不敏感匿名订单、疑似用于 AI 训练扫描的传闻 [2]。OpenAI 指出 AI 正在同时重塑网络攻防，并介绍其加强自身防御的做法以及安全团队当前可采取的措施 [3]；同时加入 PORTS-Pike 项目，扩大社区投资并支持南俄亥俄州数千个就业岗位 [4]。Simon Willison 持续扩充 markdown-svg-renderer，使其成为分享含 SVG 的 Markdown 文稿的实用工具，支持直接粘贴内容或通过 CORS 友好 URL、GitHub Gist 加载渲染 [5]。

## 全栈 / 运行时

JEP 540 Simple JSON API 已推进至 JDK 28 的 Target 状态，引入无需外部依赖的紧凑 JSON 解析与生成 API，提供不可变值层次结构，支持简单遍历与转换并强制严格语法规则，孵化期反馈将影响后续发展 [6]。同期 Java 动态还包括 Jakarta EE 12 更新、Open Liberty 2026 年 8 月版、LangChain4j 点发布、Eclipse JNoSQL 与 GraalVM Native Build tools 维护发布、GlassFish 9.0 第三里程碑以及 Groovy 6.0 第二 beta [7]。
