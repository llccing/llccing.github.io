## Angular

Angular 博客发布了关于免费书籍章节、更好的测试控制以及智能 MCP 配置的更新 [1]。

## AI

DeepSeek 发布了 V4 系列最新模型 DeepSeek-V4-Flash-0731，约 3040 亿参数（Hugging Face 上约 167GB），具备显著增强的 agentic 能力；Artificial Analysis 将其排在参数量更大的 MiniMax M3（428B）之前，输入约 0.14 美元/百万 token、输出约 0.27 美元/百万 token，性价比突出 [2]。Model Context Protocol 于 2026-07-28 推出自协议问世以来最重大的规范更新（无状态 MCP，亦称 MCP 2.0），重新点燃了社区兴趣；Simon Willison 因此推进了 mcp-explorer、datasette-mcp 相关工作，并发布了 llm-mcp-client 0.1a0 [3][4]。Vercel AI SDK 发布了 ai@7.0.47 与 ai@5.0.224 补丁，分别更新了 @ai-sdk/provider-utils、@ai-sdk/gateway 等依赖 [5][6]。OpenAI 介绍了其在欧洲以安全、安保、透明与来源实践支持负责任 AI 治理、配合欧盟 AI 法案推进的工作，并阐述了通过全栈方式让先进 AI 更强、更可负担、更广泛可用的方向 [7][8]。

## 全栈 / 运行时

Cloudflare 推出了 Media over QUIC（MoQ）配置 API，可开通独立的隔离中继，并控制谁可发布、谁仅可观看 [9]。此前 Cloudflare 已将每台服务器变为 MoQ 中继，新 API 让用户能自行配置隔离中继与访问权限。
