## Web / 框架

Vue 核心发布了 v3.6.0-rc.5 预发布版本。[1] 官方说明稳定版变更见主分支 CHANGELOG，预发布变更见 minor 分支 CHANGELOG。[1]

## AI

Vercel AI SDK 发布了 ai@7.0.76 与 ai@6.0.264 两个补丁，均修复了重复的 text 与 reasoning part ids；7.0.76 还允许带 branded IDs 的 UI 消息使用 nullish 的 metadata schemas。[2][3] llm 0.32.1 修复了全新安装失败：OpenAI Python 库不再使用 httpx，而 LLM 仅通过 openai 的传递依赖安装该库，本点版本将 openai 固定为小于 3 以临时解决，即将发布的 0.33 将从 httpx 切换到 httpx2。[4] llm-openrouter 0.7 已与 LLM 0.32 兼容，能更好地配合 OpenRouter 上的推理模型，模型现使用 OpenRouter 的 Responses API 实现。[5] Thomas Ptacek 主张即便最小的个人工具也应做真正的原生界面，因为编码智能体已把做出够用 GUI 的成本降到几乎为零；Simon Willison 提到自己 3 月用 vibe coding 完成的带宽与 GPU 监控 macOS 菜单栏应用至今仍在日常使用。[6]

## 全栈 / 运行时

Cloudflare 推出 Bot Preference Sync，强调一次声明即可同步机器人偏好。[7] 该功能会自动将 robots.txt 与面向 Search、Agent 和 Training 的 AI 机器人策略对齐，从而无需维护静态文件即可管理哪些机器人可以访问内容。[7]
