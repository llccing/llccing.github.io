## AI

OpenAI 宣布将逐步结束向 Cursor 提供模型的合同，背景是 Cursor 被 SpaceX 收购；同期还与泰国 MHESI 启动为期八周的加速器，帮助 10 家健康、康养与教育方向的初创把 AI 原型做成可信任产品。[4][5] Vercel AI SDK 发布 ai@7.0.84：在 `streamText` 结束回调中暴露已解析的结构化输出，允许在 ToolLoopAgent 设置与 prepareCall 中使用工具审批密钥，并修复 `smoothStream` 对有状态正则、空匹配正则的处理，同时更新 gateway 与 provider-utils 依赖。[3] 安全侧，Anil Madhavapeddy 观察到 OCaml 相关项目在补丁进入讨论后数分钟内就出现利用尝试，其站点约十分钟内就开始接到探测，说明“漏洞传闻”已足以驱动扫描。[2] Anthropic 将 Claude Code 的 auto mode 设为默认，并强调其抵御提示注入的作用；Johann Rehberger 则给出针对 Opus 5 auto mode 的攻击，并声称有效程度达 80。[6]

## 全栈 / 运行时

Cloudflare 在控制台为机器人与代理运营方提供 BotBase 提交入口，可跟踪状态、编辑材料，并用行为模型声明机器人如何使用内容，以便更准确地进入其目录。[7] 该公司还介绍对 1.1.1.1 DNS 缓存（Big Pineapple）布局的五项 Rust 层内存优化，单条目内存下降 56%，全网约释放 100 TB 内存。[8] Spring 生态在间隔约十周后，于 2026 年 8 月 17 日当周集中放出 Boot、Framework、Data、Security、Integration、HATEOAS、Modulith、Batch、AMQP 以及 Spring for Apache Kafka 的首个里程碑版本，值得跟进版本线的团队关注。[9]
