## AI

GitHub Models 已退休，GitHub Actions 运行因此失败，提示模型提供商已下线。之前 GitHub Models 提供模型游乐场和统一 API，通过 GitHub API 密钥在 Actions 中使用 LLM。[1] 这结束了该服务，值得关注因为它影响了依赖 GitHub Actions 的代码运行。

Simon Willison 研究 SQLite 压缩文本历史原型，将每个版本的完整文本存入大 JSON 数组，然后应用 zlib 或 zstd 压缩。由于重复字符串，压缩效果好。[2] 此原型提供新的数据库修订历史存储选项，值得关注以优化关系数据库中的版本控制。

## 全栈 / 运行时

Cloudflare 博客指出超过一半请求来自机器而非人。Agent Readiness 评估代理如何发现和阅读站点，Answer Engine Optimization 跟踪 AI 助手推荐频率。[3] 这些指标帮助站点在 AI 代理时代保持可见，值得关注因为请求模式已发生变化。

Cloudflare 博客讨论构建开放 Agentic Internet，使站点可读、可发现、可调用和可付费。代理作为新访客，有付费人类在另一端，阻止他们会影响客户。[4] 这些工具和协议旨在让发布者和代理合作，值得关注因为代理将成为重要流量来源。
