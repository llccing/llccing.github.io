## 人工智能

Simon Willison 发布了 llm 0.33，将 OpenAI Python 库升级到 3.x，并把 HTTP 客户端依赖从 httpx 切换为 httpx2；此前已有 0.32.1 的快速修复，此次为更全面的修复。[1] 他还强调，要高效使用编码智能体，关键是能自信地指示其如何改动，并自信地验证改动是否正确落地；有时需要逐行审阅，但逐行盯代码从来不是验证软件变更最有效的方式。[2] Vercel AI SDK 发布了 ai@7.0.77 补丁，更新了依赖，涉及 @ai-sdk/provider-utils@5.0.29 与 @ai-sdk/gateway@4.0.62。[3]
