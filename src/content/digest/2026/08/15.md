## Angular

Angular 官方博客发布了题为《The Forms Evolution, Web AI, and Architectural Vision!》的文章，聚焦表单演进、Web AI 以及架构愿景等主题 [1]。该文从官方视角梳理框架方向，适合关注 Angular 后续形态的开发者跟进。

## Web / 框架

Vue 核心仓库发布了 `vuejs/core` 的 `v3.6.0-rc.4` 预发布版本 [2]。预发布变更说明指向 `minor` 分支的 CHANGELOG，稳定版则参考主分支 CHANGELOG；对计划跟进 3.6 的团队，这是观察候选改动的窗口。

## AI

Simon Willison 介绍了一种“先让模型自由生成标签，再用向量嵌入对齐既有标签库”的做法，用以给旧文补标签，避免把上千个既有标签一次性塞进提示词做分类 [3]。Vercel AI SDK 分别发布了 `ai@6.0.256` 与 `ai@5.0.237` 补丁：前者更新了 `@ai-sdk/provider-utils`、`@ai-sdk/gateway` 等依赖；后者优化 `readUIMessageStream` 中累积文本的克隆方式，并修复导出值在推断 `Output` 类型时的声明生成问题 [4][5]。OpenAI 任命 Dali Rajic 为首席营收官，负责全球营收组织并推动企业落地 AI 价值 [6]；另有 Model ML 使用 GPT-5.6 Sol 贯通财务研究分析到可编辑、可追溯的 PowerPoint 与 Excel 产出 [8]。此外，alchemy-utils 发布 `0.1a1`，称在 DuckDB 导出与 CSV 导入方面有性能提升 [7]。

## 全栈 / 运行时

Cloudflare 介绍如何用协议层启发式识别 MCP 请求，帮助安全团队发现影子 MCP 流量、对已批准服务器强制 Portal-only 访问，并在受管网络路径上阻断直连 [9]。同时推出 Cloudflare Access for Workers：可将 Access 策略直接挂到 Worker，并自动覆盖路由、自定义域名、workers.dev 与预览环境，便于一键保护内部 vibe-coded 应用 [10]。
