## Angular

Angular 连续发布了 22.1.2、22.2.0-next.2 与 20.3.28 等版本，以编译器与运行时修复为主。[1][2] 中 compiler 均修正了可选链表达式的生成；22.1.2 还移除了带命名空间的 MathML script 元素，22.2.0-next.2 则在父选择器含 `::ng-deep` 时不再封装嵌套选择器。[3] 的 20.3.28 在 core 中对 concrete hosts 上的 host bindings 做 sanitize，并在 http 中改为删除 header 时精确匹配取值，有助于避免样式封装与请求头处理上的边界问题。

## AI

sqlite-utils 4.2 强化了 `table.transform()`，在复杂 alter table 场景下能更好保留 check/unique 约束、列注释等 schema 细节，并补充 check 约束相关内省属性 [5]；随后的 4.2.1 修复了因未声明 `typing-extensions` 依赖、在直接 `uvx` 运行时崩溃的问题，并加入无 dev 依赖的 CLI 冒烟测试思路 [4]。llm-gemini 0.33 增加对 Gemini 3.7 Flash、gemini-3.6-flash、gemini-3.5-flash-lite 以及 gemini-embedding-2、gemini-embedding-001 的支持，并适配 LLM 0.32，可查看 reasoning traces、启用服务端工具 [6]。Vercel AI SDK 的 ai@7.0.65 与 ai@5.0.236 补丁分别改进 `readUIMessageStream` 文本克隆、数组输出 schema 的根级 JSON Schema 定义保留、Chat `onFinish` 错误传播，以及提交状态保持到内容开始流式输出等行为 [7][8]。OpenAI 侧则有 GPT-5.6 的构建指南，以及 Ultrafast 模式预览，称 GPT-5.6 Sol 最高可达约 14 倍速度 [9][10]。

## 全栈 / 运行时

Cloudflare 观测到日全食路径上从冰岛到西班牙、葡萄牙的互联网流量受到明显影响，对应 2026 年 8 月 12 日的日全食 [11]。Certificate Transparency Monitoring 已正式可用；不再就 Cloudflare 自身为域名签发的证书发邮件，因此收到告警更值得认真查看 [12]。
