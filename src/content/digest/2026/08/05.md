## AI

Simon Willison 发布了 LLM 0.32，称其为项目初版以来最重要的版本，新增可见推理轨迹、服务端提供方工具、由 OpenAI Responses API 启用的能力，以及可内容寻址的 SQLite 日志重设计 [1]。配套的 llm-anthropic 0.26 同步升级至依赖 LLM 0.32，加入 claude-fable-5、claude-sonnet-5、claude-opus-5 等新模型，并以 -T 接口提供 WebSearch、WebFetch、CodeExecution、AnthropicMCP 等服务端工具，推理轨迹默认输出到标准错误 [4]。MiniMax 两日前发布的多模态系统 MiniMax-H3 已被移植为 MLX 包，可在 Apple Silicon 上运行，接受文本、图像、音频与视频输入并生成最长约 15 秒含音频的视频 [5]。Vercel AI SDK 发布 ai@7.0.52 与 ai@6.0.242 补丁，前者跳过对终端 output-available UI 消息部件的工具输入再校验并更新依赖，后者主要为依赖更新 [2][3]。OpenAI 就涉及自身模型的第三方网络安全评测事件作出说明并公布新保障措施 [6]，同时推出面向 ChatGPT Work 与 Codex 的教育插件，服务 K–12 教师、高校教育者与学生 [7]。

## 全栈 / 运行时

Cloudflare 提出 Agent Development Lifecycle，并介绍支撑该流程的平台原语，以应对智能体写代码速度快于团队审查、部署与维护的现状 [8]。同日宣布 Cloudflare Wallets，面向 agentic Internet 提供可编程钱包，借助 x402 协议让智能体在明确安全护栏内自主购买 API 与内容 [9]。Node.js 发布 26.6.0（Current）与 24.19.0 'Krypton'（LTS）：前者含 ffi 的 getCurrentEventLoop、test_runner 的 context.log() 与 test:log 事件等次要版本特性 [11]；后者实现 blob.textStream()、更新 OpenSSL 构建配置以支持压缩等 [12]。Java 方面，Embabel Agent Framework 达到 1.0，基于 Spring AI 让 Java/Kotlin 开发者以类型化领域对象定义智能体，并支持多模型提供方与规划加状态机的工作流 [13]；InfoQ 周报还涵盖面向 JDK 28 的 OpenJDK JEP、GPULlama3.java 1.0、Micronaut/Quarkus/JobRunr 点版本、Maven 4.0 第六个 RC，以及 Jakarta Agentic AI 1.0 首个里程碑等 [10]。
