## AI

Vercel AI SDK 连续发布补丁：`ai@5.0.245` 停止从 `@ai-sdk/provider-utils/test` 再导出 `createTestServer` 与 `TestResponseController`，使 `ai/test` 无需 `msw` 或 `vitest` 即可加载，相关 API 需改从 `@ai-sdk/test-server/with-vitest` 导入，并更新了 `@ai-sdk/provider-utils` 与 `@ai-sdk/gateway` [1]；`ai@7.0.78` 则在重新校验后的工具输入无效时，以模型可见的工具错误继续已批准的 `generateText`、`streamText` 与 `WorkflowAgent` 轮次 [2]。llm-anthropic 0.27 主要为兼容 anthropic Python 库 v1.0.0（由 httpx 切换到 httpx2），并指出 OpenAI Python 库 v3.0.0 做了同样变更 [3]。OpenAI 宣布 GPT-5.6 已在 Kiro 中可用，以更好的性价比协助开发者规划、构建、评审和测试软件 [4]。另有一篇介绍 Linux 上把 SQLite 数据库文件直接当作可执行二进制使用的做法：将文件格式中偏移 68 字节处的 4 字节 application ID 设为 SELF（Structured Executable & Linkable Format），再把 ELF 各组成部分放入若干 SQLite 表 [5]。
