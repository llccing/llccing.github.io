## Web / 框架

Vite 发布了 v8.2.1[1]。本次条目未展开具体变更，仅指向对应 CHANGELOG 以了解细节。

## AI

Vercel AI SDK 发布了 ai@6.0.246 与 ai@7.0.56 两个补丁版本[2][3]。6.0.246 主要更新了依赖；7.0.56 在语言模型调用结束回调与遥测 span 上暴露了 provider metadata，并修复 `generateVideo` 重试时 `doStart` 的幂等性：在重试闭包外生成幂等令牌并以 `idempotency-key` 头转发，避免丢失响应后重试产生重复、可计费的生成[3]。Datasette 1.0a38 修复了在同一数据库中混合公开与私有表、且用权限系统配置访问时的 SQL 注入问题；管理员被建议在相关数据库上禁用 `execute-sql` 权限，以防仅有公开表访问权的用户借原始 SQL 触及私有表[4]。该安全修复已回移植至 0.65.3[5]。OpenAI 改进了 ChatGPT 中 GPT-5.6 Sol 的准确度与一致性，并为免费用户扩大 GPT-5.6 Luna 访问及日常无限对话[7]；同时与美国心理学会推进面向青少年心理健康与负责任 AI 使用的循证指引、资源与保障[8]。另有 Simon Willison 关于技术博客的访谈内容被收录[6]。

## 全栈 / 运行时

Cloudflare 推出 AI Search，可直接指向自有文件与网站数据创建搜索，无需拼接各类 Cloudflare 原语，并预告新定价模型[9]。MCP 下一代版本将核心重写为无状态并适配 Workers，涵盖协议升级、功能生命周期、SDK 迁移路径，以及已在生产环境运行的早期采用者反馈[10]。
