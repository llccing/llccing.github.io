## Angular

Angular 发布了 21.2.23。[1] 该版本在 platform-server 中将 domino 更新到最新版本，提交类型为修复。[1] 这是一次针对 platform-server 依赖的维护性更新，使用该包的项目可据此评估是否跟进。[1]

## Web / 框架

Vue 核心库发布了 v3.6.0-rc.8；材料说明稳定版变更见主 CHANGELOG，预发布变更见 minor 分支 CHANGELOG。[2] Vite 发布了 v8.3.0，构建阶段避免对已记录的 preload 依赖执行 settling，以提升性能。[3] 该版本还修复了代码帧位置对 CRLF 换行的处理，并改为仅将完整的 node_modules 路径段视为依赖。[3] Vue 进入 3.6 RC、Vite 同步放出 8.3.0，前端框架与构建工具的版本节奏值得跟进。[2][3]

## AI

Datasette 同时发布 1.0a39（当前 alpha 系列）与 0.65.4（稳定 0.65.x 系列）两份安全补丁；若在公网运行 Datasette 实例，应应用这些修复。[4] Farid Zakaria 的工作在浏览器中通过 WebAssembly 运行 qemu-wasm 驱动的 x86_64 Linux 虚拟机，可启动过去 13 年中的任意 Nix 包，并支持 URL 寻址。[5] Shopify 将移动端从 React Native 转回独立的 Swift 与 Kotlin 代码库；材料回顾其 2020 年改用 React Native 的原因，包括避免重复实现同一功能、让开发者跨栈工作，以及减少特性对齐、把时间用在交付价值上。[6] OpenAI 介绍 César de la Fuente 实验室使用 Codex 与 ChatGPT，在现存和已灭绝基因组中搜寻抗微生物候选分子以应对耐药感染，并推出 ChatGPT Work 中的 Data agent，可用自然语言连接公司数据、发现洞察并构建交互式仪表盘。[7][8] Vercel AI SDK 发布 ai@5.0.255 与 ai@6.0.280：两者均对未分类的空图像结果进行重试、引入提供商无关的结果可重试性分类并经 AI Gateway 保留，且将 Google Vertex 等过滤结果标为终态；5.0.255 另修复 Node.js 下文本 data URL 解码，6.0.280 另修复在 Cloudflare Workers 中不以 receiver 调用 atob 的兼容性。[9][10]

## 全栈 / 运行时

Cloudflare 的 1.1.1.1 现已使用 NIST 后量子算法 ML-DSA-44 校验 DNSSEC 签名。[11] 该算法签名长度为 2,420 字节，材料说明了如何在大规模部署中处理这一体积以及降级风险。[11] 公共 DNS 解析器支持后量子 DNSSEC，核心关注点正是超长签名与降级风险的工程取舍。[11]
