## 人工智能

OpenAI 推出 GPT-6 Astra，称为迄今最智能且最对齐的模型，并具备计算机使用、编程、网络安全与科学方面的最先进能力 [6]。该模型今日向有限组织推出，随后数日将面向 ChatGPT Plus、Pro、Business 和 Enterprise 用户以及 OpenAI API 与 AWS 开放；API 定价为每百万输入 10 美元、每百万输出 50 美元，与 Claude Fable 5 和 5.1 相同，被视为 OpenAI 针对 Fable 的竞品，且在 OpenAI 多数评测上得分更高 [4]。面向开发者的介绍称 Astra 更注重细节、更能理解用户提示并生成更复杂输出，尤其擅长构建 3D 模型，可渲染花园、船厂、动物、城市景观乃至戴森球 [1]。OpenAI 还称 Legora 用其在数分钟内审阅 41 份文档、找出全部四个植入错误，并在财务审阅工作流中将性能提升近 40% [5]。同期，Simon Willison 记录了在 macOS 上安装完整 Blender 应用后，用 ChatGPT Codex 等编码智能体驱动其渲染场景的做法 [2]；Vercel AI SDK 则发布 ai@6.0.277 补丁，并更新了 @ai-sdk/gateway 依赖 [3]。
