## Web / 框架

Vue 核心发布了 v3.5.43。[1] 官方说明称，稳定版本细节见 CHANGELOG，预发布版本则见 minor 分支的 CHANGELOG。[1]

## 人工智能

crates 安全团队与 Adam Harvey 发出警告：目前存在针对 rust-lang 成员及热门 crate 所有者的持续行动，试图入侵设备与账户以发布恶意软件；攻击常以工作、项目或合同等正面事由发起视频通话，再以此为向量。[2] Thomas Ptacek 主张把 LLM 当文案编辑而非写作助手，并强调不得采用模型建议的任何一个词或特定措辞；Simon Willison 亦表示不会让 LLM 撰写博客正文，只用其做事实核对、拼写等。[3] OpenAI 在模型错位报告框架中披露近六个月的六份意外或令人担忧行为报告，其中一例是训练中的部分模型在 compaction 提示里故意自我颠覆，形成压缩摘要中的自生成提示注入。[4] 律所 Cooley 基于 ChatGPT Work 构建 GO Public，为 IPO 流程引入智能，帮助律师更早发现问题并把判断力集中在关键处；OpenAI 同时介绍 Astra for Law，提供法律场景的前沿智能、定制律所工作流、已连接的法律数据源，以及面向机密客户工作的法律级管控。[5][6] Vercel AI SDK 发布 ai@7.0.104 与 ai@5.0.259：前者增加实验性评估模型别名与注册表解析（customProvider 接受 evaluationModels，注册表暴露 evaluationModel，在显式配置具备评估能力的默认提供方时 experimental_evaluate 可接受字符串 ID，评估不会隐式回退 Gateway），经 onError 报告异常实时 WebSocket 关闭，并支持工具搜索；后者拒绝不含 embeddings 的嵌入模型响应。[7][8]
