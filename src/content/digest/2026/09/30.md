## AI

OpenAI 在 DevDay 2026 介绍了 GPT-6.1 Sol：面向编码、计算机使用和专业工作，智能水平接近 Astra，标准 API 输入与输出 token 价格为 Astra 的五分之一 [5]。同期回顾列出二十余项发布，涵盖 GPT-6 Astra、ChatGPT、Codex、API、安全以及面向构建者的新工具 [6]。Simon Willison 在旧金山 Fort Mason 现场直播主题演讲，并因此推迟了 GPT-6.1 Sol 相关内容的发布 [3][4]。Vercel AI SDK 的 ai@5.0.270 与 ai@6.0.297 均修复了流恢复时对已水合部分静态工具输入的保留、以可选 SSE 心跳维持空闲 UI 消息流，以及在默认重连 URL 中编码聊天 ID（使斜杠、查询分隔符和片段留在 ID 内，拉取前拒绝独立的 `.` 与 `..` ID；`prepareReconnectToStreamRequest` 返回的自定义 URL 不变）[1][2]。5.x 还将原型同名的 tools、providers 与 provider metadata 保留为自有属性且不修改查找对象原型 [1]；6.x 则澄清提供商执行的工具错误会绕过 UI 流的 `onError` 以保留提供商错误数据，流错误与无效工具调用仍走该回调，运行时行为不变 [2]。

## 全栈 / 运行时

Cloudflare 正在构建内部 AI 工具 CryptoLabe，用于在代码库中发现密码学实现、梳理依赖，并推进到 2029 年完成全面后量子迁移 [7]。Universal SSL 上线十二年后，Cloudflare 申请成为证书颁发机构，计划结合既有根证书、ACME 优先方案与 Merkle Tree Certificates，打造面向开放网络的后量子 CA [8]。Java 生态在 2026 年 9 月 21 日当周密集发布里程碑：Spring Boot、Spring Batch、Spring Security、Spring AMQP、Spring Integration、Spring Data、Spring Framework、Spring for GraphQL 与 Spring for Apache Kafka 迎来第二里程碑，Spring AI、Spring Cloud、Spring Web Services 与 Spring LDAP 迎来第一里程碑 [9]。
