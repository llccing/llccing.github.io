## AI

Google 发布了 Gemini 3.8 Live 与 Gemini 3.8 Live Extended Thinking，两款新的 speech-to-speech 模型，形态与 OpenAI 的 GPT-Live 系列相近。[1] Simon Willison 据此提供了 Gemini Live audio 工具，并将 GPT-6 Astra Extra High 指向相关文档以协助构建。[1] Vercel AI SDK 的 ai@7.0.102 在既有 WebSocket 路径之外，增加可选的浏览器直连 WebRTC，用于实验性的客户端委托 Live 对话：经应用端点以 `api.session` 交换 SDP，配置由服务端持有的 data-channel 权限，并保持已提交的 React session 所有权。[2] 采集跟随所选 sender track，借用的 track 仍归调用方；断开恢复与收尾保持有界。应用仍需自行处理客户端委托并提交上下文，Live session 更新与 Responses 委托仍不受支持。[2]

## 全栈 / 运行时

Cloudflare 让站点所有者可以在搜索中保持可发现的同时禁止用于 AI 训练，并以新的控制项和 Accountable 标识，与 Apple、Google、Microsoft 建立共享模型。[3] 同一时期，访问可按单个 Worker 限定范围，并可分配更细的 Developer Platform 角色，使同事、CI token 与 agent 只获得调试、部署或监控所需权限。[4]
