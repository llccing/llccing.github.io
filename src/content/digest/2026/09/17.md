## Angular

Angular 放出 22.2.0-rc.0，并同步发布补丁 22.1.7。[1][2] 两个版本的 compiler 都修复了同一问题：在追加非空断言之前，先包装 `@for` 的集合表达式。[1][2] 预发布版 compiler-cli 新增 `strictUnclaimedEventNames` 选项，用于捕获拼写错误的 output 绑定；22.1.7 的 core 则在 `getDirectiveMetadata` 收到 null 或 undefined 时改为返回 null。[1][2]

## AI

Datasette 0.65.5 修复了请求表名带尾随换行即可绕过表权限、暴露私有行的问题；1.0a40 包含同一安全修复，并让插件可通过 `datasette.add_background_task()` 启动和管理后台任务。[3][4] Vercel AI SDK 的 ai@7.0.105 在未配置默认 provider 时，经 AI Gateway 解析 evaluation model ID，并支持自定义 provider 中的字符串别名，同时将 `@ai-sdk/gateway` 更新到 4.0.85；ai@6.0.285 则跟随将 gateway 更新到 3.0.196。[5][6] Claude Cowork 与 chat 合并为同一个 Claude，既可处理简短提问，也可接手限时报告，即使合上笔记本后仍能继续，将先向 Pro 和 Max 用户在 web、桌面和移动端的 Claude 应用中分批推出。[7] OpenAI 公布用于跟踪、调查和披露模型错位的框架，并附带六份意外或令人担忧的模型行为报告；同时与 AARP 合作，在美国 10 座城市为 1000 名老年人提供免费、动手实践的 ChatGPT 工作坊。[8][9]

## 全栈 / 运行时

Cloudflare 指出，现代店面表面看起来正常时，恶意 JavaScript 仍可能悄悄抽走收入、劫持点击或改写分析数据，其 Client-Side Security 用机器学习模型把规避型客户端攻击交给分析人员调查。[10] Node.js 26.9.0（Current）以若干 SEMVER-MINOR 加密能力为看点，包括通用 MAC API，以及从 OpenSSL providers 发现 cipher 与 hash。[11] Oracle 发布 Java 27，这是 JDK 25 之后第二个非 LTS 版本，最终特性集含九项 JEP（其中五项仍处于 preview 与 incubator），重心是加强安全、面向未来的语言创新，以及 Java Verified Portfolio 下的项目，同期还有 Helidon 27 与 JavaFX 27。[12]
