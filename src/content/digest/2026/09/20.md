## 人工智能

Simon Willison 发布 datasette-auth-github 1.0。该 GitHub 登录插件用于 agent.datasette.io 演示站点，此前设置 cookie 时未带 Max-Age，认证会话会在浏览器会话结束时失效；在 Mobile Safari 中这类会话结束似乎相当频繁，且与应用使用方式相对独立，此次版本修复了该问题。[1] 他还记录了在美国加州 Pillar Point Harbor 拍摄的加州海狮与 Brandt's Cormorant，并称拍照后才注意到北方塘鹅 Morris 从标牌底座后方探出。[2] OpenAI 推出澳大利亚青年安全蓝图，作为保护并赋能年轻人的六支柱更安全 AI 体验路线图；另介绍 ChatGPT Work 与 Codex 分析如何帮助团队理解 AI 使用与支出、识别培训需求，并将采用情况与业务成果挂钩。[3][6] Vercel AI SDK 发布 ai@7.0.106 与 ai@6.0.286 补丁，均涉及模拟文本流时保留提供商元数据、在流式步骤结果中报告 prepareStep 模型、避免 UI 消息流提前停止导致未处理 rejection，以及保留仍待审批所需的工具调用；7.0.106 还修复序列化工具输出中的原型名属性、提供商响应流失败时关闭遥测 span，以及流式响应元数据回退使用 prepareStep 选定模型，6.0.286 还修复模型调用中止或超时时取消提示附件下载，并支持流式输出 null 与空字符串 JSON 部分结果，以及最终 tool-loop 步骤的结构化输出。[4][5]
