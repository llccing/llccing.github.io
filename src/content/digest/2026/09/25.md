## Web / 框架

Vite 发布了 v8.3.1，本次均为缺陷修复：两轮非 major 依赖更新，以及一次 rolldown 相关依赖更新 [1]。该补丁主要做依赖同步，对使用 Vite 8 与 Rolldown 的项目值得跟进。

## AI

Simon Willison 发布 commit-rewriter 0.2，支持在非默认分支上运行，可用 `--branch` 指定目标分支 [2]。Datasette 1.0a41 由 Alec Garcia 加入 OpenTelemetry 支持，并将全部模态对话框重构为单一 Web Component，已文档化供其他插件复用 [3]。Vercel AI SDK 发布 ai@7.0.114，修复按遥测白名单过滤 tracing-channel 上下文的问题，并澄清 `allowSystemInMessages` 允许包括指令文本在内的全部系统消息；ai@6.0.291 同步更新了 gateway 依赖 [4][5]。OpenAI CEO Sam Altman 在联合国安理会就 AI 安全、人类控制与国际合作发表讲话；Harvey 使用 GPT-6 Astra 生成更结构化、更贴合上下文的法律文书，使律师能把精力放在策略上 [6][7]。Simon Willison 还发布 LLM 插件 llm-typesafe 0.1a0，为 LLM 增加对 TypeSafe AI 新模型 Jev 的支持，安装并设置 API 密钥后可提出是/否形式的 “noul” 问题 [8]。

## 全栈 / 运行时

Cloudflare 介绍了其如何应对 Containers 中的跨租户数据暴露漏洞。外部安全研究人员 Accomplish 发现该漏洞可能暴露先前工作负载残留的磁盘数据，Cloudflare 说明了问题机制、调查过程以及修复步骤 [9]。
