## Angular

Angular 同时发布 22.2.0-next.5 与 22.1.5。[1][2] 两个版本的 compiler-cli 都修复了扩展诊断，用于检查未被调用的 signal 别名。[1][2] 预览版在 core 中新增用于测试指令的工具；22.1.5 则取消过期的 debounce 定时器，以避免定时器泄漏。[1][2]

## Web / 框架

Vite 发布 v8.3.0-beta.0。[3] 该版本可在 `server.watch` 中接受 Rolldown 的 watch 选项，新增 `closeServer` 与 `closePreviewServer` 钩子，并加入顶层 `tsconfig` 选项。[3]

## AI

Vercel AI SDK 的 ai@7.0.91 为 `streamText` 在流式响应开始后收到的提供商错误增加可配置恢复：显式配置 `streamRetries` 可做隔离重试，含一次经 `StreamTextOnErrorRetryCallback` 引导、且 `streamRetries: 0` 时有界的恢复；恢复后的结果与元数据只反映成功那一次，并保持现有 `StreamTextOnErrorCallback` 与仅日志观察行为兼容；同系列 ai@5.0.251 则更新了依赖（含 `@ai-sdk/gateway@2.0.145`）。[4][8] llm-gemini 0.34 新增模型代码 `gemini-3.8-flash`（对应 Gemini 3.8 Flash，含低、中、高思考级别），并修复异步响应未能记录已解析模型版本的问题；datasette-mcp 0.2 为首个非 alpha 版本，将 `execute_sql` 的 `rows` 从数组的数组改为对象数组，以降低较弱模型弄错列对应关系的风险，并依赖 `mcp >=2.1.1`。[5][9] Anthropic 公开 Claude 消费端应用（Claude.ai 与移动应用，不含 Claude Cowork 与 Claude Code）的系统提示及历史变更，文档由单页改为重新编排；Simon Willison 指出新系统提示明显不愿复现歌词。[6] OpenAI 方面，ATV Big Air Tour 用 ChatGPT Work 加快营销与周边等事务，将三天工作压缩为三小时，并在 15 分钟内把商品照片做成库存网站；医疗机构现可将 EHR 及其他行业数据接入 ChatGPT，帮助临床人员安全获取患者上下文、医学研究等信息。[7][10]
