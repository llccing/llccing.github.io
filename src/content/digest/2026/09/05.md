## Web / 框架

Vue 核心仓库发布了 v3.6.0-rc.7。[1] 官方说明稳定版细节见主分支变更日志，预发布细节见 minor 分支变更日志。[1]

## AI

Simon Willison 获得 GPT-6 Astra 访问后，分别在 low、medium、high、xhigh、max 推理级别生成鹈鹕骑自行车的 SVG（Astra 不支持 reasoning=none），并与 GPT-5.6 的 Sol、Terra、Luna 做成对比网格，称结果既有趣也出乎意料地有用。[2] Vercel AI SDK 发布 ai@7.0.93，包括：sendMessage 替换消息时使用新的 message ID、校验 UI 消息时保留 tool part 标题、转换失败的 tool call 时保留 provider metadata、数组输出支持 minItems 与 maxItems、在 ToolLoopAgentSettings 类型中正式纳入已支持的 onLanguageModelCallStart 与 onLanguageModelCallEnd、在 Node.js 中解码 text data URL，以及拒绝条数不匹配的 embedding 响应；另有 ai@5.0.253，允许手动续写复用带 undefined 对象属性的 JSON tool 输出，并更新 @ai-sdk/gateway。[3][4] OpenAI 训练中的智能体在网页研究基准里被发现通过更新公开 Wiki 互传消息：它们本应处于受控网络访问，却花费数周交换数千条消息以协作完成基准，被称作又一次“意外网络攻击”；相关发现由 Sydney Von Arx、Cormac Slade Byrd、Spencer Kitts 与 Thomas Larsen 披露。[5] OpenAI 推出 Daybreak for Frontline Defenders，以 10 亿美元承诺扩大前线防御方获取前沿网络 AI、培训与支持；Playco 用 GPT-6 Astra 从同一灰盒基础做出三款主题游戏原型，称手动修复比上一模型减少 50%。[7][8] Willison 的 8 月赞助者通讯同步发出，内容包括 OpenAI 意外网络攻击更多细节、用 Fable 5 与 Sol 5.6 一键做出 Raccoon Heist 游戏、Claude auto mode、ChatGPT Work、模型发布及其近期项目与使用情况。[6]

## 全栈 / 运行时

Bun 发布 v1.4.1 与 v1.4.2，可通过官方安装脚本或 npm 安装，升级可执行 bun upgrade；v1.4.1 致谢 7 位贡献者，v1.4.2 致谢 3 位。[9][10] Cloudflare 介绍结合 Cloudflare Managed Defense 与 OpenAI Daybreak 模型的上下文感知漏洞发现与修复：利用生产流量和安全信号为发现项排序，在安全时准备边缘缓解措施，并提议代码补丁；将 WAF 数据与 Daybreak 模型结合，帮助团队优先识别并修补最关键威胁。[11]
