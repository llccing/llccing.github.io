## Angular

Angular 博客发布了新内容，主题从在 Cloudflare Workers 上运行边缘渲染的 Angular 应用，延伸到打造逼真语音等相关实践。[1] 现有条目仅给出上述主题线索，未提供更多实现细节。[1]

## 人工智能

Vercel AI SDK 发布 ai@7.0.153，修复非流式 Responses API 在多条助手消息含 JSON 时结构化输出失败的问题；提供方可单独给出用于解析的结构化输出文本，使 OpenAI 与 Azure Responses 模型选取最后的 final_answer，同时保留全部生成内容、注释、对话历史和 token 用量。[2] Simon Willison 的 battledrones 更新至 v14 Compass Rose，新增四人在线模式与四向旋转对称地图，此前地图仅限两人，空位可由 AI 填充，并支持基于 WebSocket 的非音频多人模式。[3] OpenAI 与波兰 NASK 合作推进 AI 安全、安保与技术研究，以加强防护并支持更具韧性的数字生态。[4] Uber 向逾 3 万名员工推出 ChatGPT Work，用于研究、分析数据、制作演示文稿并完成复杂工作流。[5]
