## AI

Vercel AI SDK 发布 ai@7.0.150，新增 `experimental_streamSpeech`：可从字符串，或文本增量/文本片段的数组、可迭代对象或流中流式生成语音，片段可带可选的 `voice` 与 `providerOptions`，依赖实现 `Experimental_StreamingSpeechModelV4` 的语音模型，并返回单消费者的 `audioStream`/`fullStream` 以及 `usage`、`warnings`、`responses`、`providerMetadata` 等 Promise；提供商 `error` 部分非致命，默认经 `onError` 报告，用户中止或取消会拒绝结果 Promise。[1] 同系列 ai@6.0.314 修复 `toolChoice: 'none'`：将其转发给 Hugging Face Responses API，并在 `generateText` 与 `streamText` 本地执行前拒绝工具调用，流式工具部分会被扣留以免客户端工具据此执行，且不会对已拒绝的调用触发 `experimental_repairToolCall`。[2] OpenAI 推出 Decisions API，定位为面向任意应用的快速、聚焦、低成本决策，以构建更灵敏的应用；另有一文解释该公司语境下的 forward deployed engineering（FDE）。[4][6] Anthropic 宣布将 Agent Skills 标准捐赠给 Linux Foundation 下的 Agentic AI Foundation（AAIF），以保持开放、社区驱动与厂商中立；AAIF 由 Anthropic 与 Block、OpenAI 于去年共同创立，此前还向其捐赠过 Model Context Protocol。[5] Simon Willison 另发文提到荷兰另类摇滚乐队 De Staat 的 FREEDOM 官方音乐视频，称这是他的第一次，并点出片中 00:44 处。[3]

## 全栈 / 运行时

Cloudflare 通过覆盖 80 项控制的审计，获得韩国 ISMS 认证，并介绍如何在规模上本地化合规：本地化用户同意流程、在边缘适配社交注册路径，以及验证其全球安全项目。[7] 该公司还与 Commerce.com 合作，使近 10 万个 Commerce.com 域名通过 Cloudflare 上的 WebMCP 向 AI 代理提供真实购物工具，一次性在全部店铺启用，同时让各商家保持控制权。[9] Bun 发布 v1.4.4，给出安装与 `bun upgrade` 升级方式，并感谢 39 位贡献者。[8]
