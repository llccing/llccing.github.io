## Angular

Angular 发布了 22.3.0-next.1 与补丁 22.2.2。[1][2] 两个版本的 compiler 都修复了 ::ng-deep 检测状态在规则之间泄漏的问题，并避免在解析实体时做原型查找。[1][2] 同类修复同时进入 next 通道与 22.2 稳定线，关系到样式封装检测是否串扰，以及实体解析是否会受到原型链干扰。

## Web / 框架

Vite 发布了 v8.3.4。[3] 该版本在 bundled-dev 中支持 `import.meta.hot.acceptExports`，便于按导出做热更新接受。[3] 同时修复了会改写 HMR 默认值的问题，并在启用 chunkImportMap 且 base 非根路径时纠正 preload 行为。[3]

## AI

Vercel AI SDK 发布 ai@7.0.136：流式输出在模型响应结束时停止 `chunkMs` 与 `firstChunkMs`，避免长时间运行的本地工具触发模型输出超时，并为每次重试提供新的输出超时预算；`stepMs` 仍覆盖含本地工具在内的完整步骤，依赖同步更新至 `@ai-sdk/gateway@4.0.110`。[4] Simon Willison 推出代币计数 CLI ttok 0.4（基于 tiktoken），时隔数年修复 Click 警告、更新 CI，并新增 `--list-models`，可用 `uvx ttok` 对文本计数；他还记录了用 Parseable 搭配 Datasette 查看 OpenTelemetry 追踪，Parseable 是新的可观测平台，含 AGPL 开源 Rust 实现（约 180MB 单二进制）、企业版与云托管。[5][9] Mistral 发布 Mistral Large 4（Le chonk）预览：1 万亿参数、490 亿活跃参数，在自有 3800 块 NVIDIA Grace Blackwell GPU 集群上训练，API 已可调用，并承诺本月底放出开放权重；经 Mistral API 仅支持 none 与 high 两档推理级别。[8] OpenAI 披露 Oracle 在招聘、工程与运营中用 ChatGPT Work 和 Codex，把专家知识变成可重复的快速工作流；Pollo AI 则借助 GPT-5.6、GPT-6 Astra 与 GPT-Image-2.5，把创意做成精细图像与电影感视频广告。[6][7]

## 全栈 / 运行时

Cloudflare 介绍了 Radar 的改版：用交互式地图和标准化组件，让实时全球流量与中断数据更容易被记者、偏非技术的研究者和普通用户使用。[10] 改版在简化导航的同时保留原有技术深度。[10]
