## 人工智能

eMudhra 的八张中间 CA 证书私钥已遭泄露，这些证书链至 Mozilla、Microsoft、Apple 和 Chrome 根证书计划以及众多下游信任库所信任的根，因此任何内置可信证书列表的软件都需要更新，相关软件更新进展有 GitHub 仓库在跟踪。[1] Simon Willison 最新的 vibe coding 实验是类似 Command & Conquer 的即时战略游戏 Battle Drones，他承认是靠让 Claude「把它做得好玩得多」才真正可玩，并支持附近设备通过音频同步游戏状态进行多人游戏。[2] Vercel AI SDK 发布 ai@7.0.147 与 ai@7.0.146：前者修复流式 UI 消息部件中未能保留已修复工具名的问题；后者为实验性决策调用增加 maxOutputTokens 和 reasoning 并转发给基于语言模型的决策（语言模型适配器在未指定时保持 reasoning 关闭，原生决策提供方在不支持时发出警告），同时修复剪枝工具调用时残留的孤立 reasoning（含连续的 summary 与 reasoning-file 部件），以及可选工具在 tool call、result、error、denied output 和 execution 事件类型中错误加入 undefined 成员的问题。[3][6] OpenAI 披露，一家独立的 Schlotzsky’s 与 Cinnabon 加盟商使用 ChatGPT Work 将现金对账时间减少 94%、菜单重新定价时间缩短 95%，并搭建了有望释放 10 万美元现金流的工作流；Terminal X 的 Eval Agent 按 54 条标准对输出打分，在 GPT-6.1 Sol 下能多发现 25% 偏离基金授权的情况，与资深投资人判断的一致率达 88.6%。[4][5]

## 全栈 / 运行时

在发现八张 eMudhra 中间证书使用弱密钥后，Cloudflare 正在部署缓解措施并发布客户端更新，同时说明此次事件的影响、自身响应，以及客户与开发者接下来应采取的行动。[7] Cloudflare 还在协作推进 tsrs，这是将 TypeScript 移植到 Rust 的项目，速度最高可达原来的 8 倍，内存占用减少 70%。[8]
