## Web / 框架

Chrome 155-156 的 WebGPU 更新加入了 WGSL fragment_depth 扩展、未对齐纹理压缩、srgb-linear 与 display-p3-linear 色彩空间，以及 snorm10-10-10-2 顶点格式等能力 [1]。与此同时，Chrome 开始交付 JPEG XL：压缩效果优于 JPEG，并带有内置 HDR 支持和无损 JPEG 转码 [2]。前者扩展了浏览器图形管线可表达的格式与色彩范围，后者则直接关系到网页图片体积、动态范围与存量 JPEG 的无损迁移，值得前端与图形开发跟进。

## AI

Python 3.15 已发布，配套 What’s new 指南由 3.14 与 3.15 发布经理 Hugo van Kemenade 整理；Simon Willison 因此可以告别 3.10、开始使用 3.11 起的特性，并点名最期待显式惰性导入（explicit lazy imports）[3]。Vercel AI SDK 同期放出 ai@7.0.138 与 ai@5.0.274：两边都修复了页面重新可见时中断聊天流的恢复，避免 `useChat` 在 `resume: true` 下因共享 Chat 实例中途重挂载而再发一次 resume，并修正匹配工具调用所在消息的工具输出，以及跨 SDK 版本的全局类型冲突；7.x 还提到恢复重放流时的重复消息片段与可选的共享 citation 表示，5.x 则补充了停止时等待聊天流清理、按稳定 ID 更新流式消息等修复 [4][5]。另有 web-edit 0.1a0：这是一个用 Python 做成的文件夹文件查看/编辑 Web UI，意图跑在 Tailscale 上，方便在手机上改文件、避免凭证经 LLM 中转 [6]。datasette-ports 0.4 已适配最新 Datasette，并显示检测到的 PID，便于挂接 Python 3.15 的采样分析器 [7]。

## 全栈 / 运行时

Cloudflare Logpush 现支持 Transformers，可在导出前用 SQL 过滤、脱敏和重塑日志流；该能力由 Apache DataFusion 与 Apache Arrow 驱动，变换直接作用在日志到达目的地之前 [8]。InfoQ 2026 年 10 月 5 日这期 Java 周报则汇总：面向 JDK 28 的 OpenJDK JEP 已提议纳入目标，Lazy Constants 升为 Candidate；Apache Grails 8.0 与 Open Liberty 20.0.0.10 正式发布，TornadoVM、Infinispan、LangChain4j、Spock 有点版本更新，GlassFish 有维护版本 [9]。一边是日志在离开平台前即可按 SQL 裁剪与改写，一边是 JDK 路线图与多条 Java 框架同步推进版本，运行时与全栈侧都值得对照现有导出链路和依赖矩阵。
