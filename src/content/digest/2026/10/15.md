## Angular

此次材料中出现 Angular 22.2.3、22.3.0-next.2 与 20.3.34 三条发布线。[1][2][3] 22.2.3 与 22.3.0-next.2 均在 common 中加固参数编码以抵御原型污染，并在 compiler 中让控制流内容投影诊断检查 `@boundary` 块。[1][2] 20.3.34 则修复 core 在出错时泄漏 i18n 标志的问题，同时在 http 中为同源绝对 URL 启用 XSRF 保护。[3] 这些改动集中在编码安全、请求防护与模板诊断，直接关系到运行时安全与编译期正确性。

## Web / 框架

React 于 2026 年 10 月 14 日分别发布 19.3.1、19.2.9 与 19.1.10。[4][5][6] 三个版本的说明一致，均改进 React Server Components 的传输协议，对应改动编号为 #37845、#37844、#37843，作者为 @unstubbable 与 @eps1lon。[4][5][6] 同一主题沿多条版本线同步放出，说明该传输协议调整被当作跨版本的重要修复。

## AI

Simon Willison 记录了又一次 Claude 游戏实验：在默认 iPhone 应用的聊天模式（非 Claude Code）中，用 Claude Opus 5.5 Max 生成 Three.js 游戏 Tree Appreciator，展示两棵算法生成的树并比较差异。[7] 他还转述独立开发者 Popcar 的文章：AI 正在大规模反编译现有游戏，催生游戏混搭以及把旧作跑在新硬件（常借助浏览器与 WebAssembly）的保存项目，并同时写出此事的利与弊。[8] OpenAI 侧，Amp 使用 GPT-6 Astra、Ultrafast、GPT-Live-1 以及 Sign in with ChatGPT，把智能体用到代码之外；SentinelOne 则借助 OpenAI Daybreak，将恶意软件分析从数周缩短到数小时。[9][10] Vercel AI SDK 发布 ai@5.0.276 与 ai@7.0.140，后者新增可配置的工具调用执行并发，并分别更新了对应的 gateway 依赖。[11][12] Meta 发布 Muse Wonder 与 Muse Wonder Full，自称其最强模型；Artificial Analysis 将 Muse Wonder (Max) 评为与 GPT-6.1 Sol 相当，Simon Willison 据此更新 llm-meta-ai 至 0.2，并认为它们可能是 Meta 首批 Fable 级别模型。[13]

## 全栈 / 运行时

Cloudflare 写道，Yandex 数据中心遇袭后，外界以为相关机器人会停摆，但数据显示搜索爬取虽已停止，恶意机器人只是迁到其他网络。[14] 另一篇则介绍 Hyperdrive 在加入 MySQL 支持时，定位到缓存查询结果时的罕见协议缺陷（约 0.001% 错误率），修复后 Hyperdrive MySQL 已普遍可用。[17] Node.js Current 线发布 26.12.0：在缺少 WebAssembly 或 RX 支持时抛错，并新增 `websocketMask()` 与 `websocketUnmask()`。[15] LTS 线 24.22.0（Krypton）则在 crypto 中加入 `crypto.parsePKCS12()`、通用 MAC API，以及从 OpenSSL providers 发现 cipher。[16]
