## 人工智能

本周 GitHub Universe 的会议徽章与去年类似，仍是一台带彩色屏幕的完整计算机。Simon Willison 继续对其改造，并遇到 Steve Francia；后者借助 Gemini 在徽章上实现了完整 NES 模拟器，并更进一步部署了模拟器。[1] Vercel AI SDK 发布 ai@7.0.155，移除 TypeScript 类型已能保证的运行时输入校验：`streamText`、`generateText`、`generateObject` 与 `streamObject` 不再对照 `ModelMessage` schema 校验消息，以去掉随消息历史线性增长、且在每个 `streamText` 步骤都会付出的开销，同时取消对调用设置、steering messages、工具调用配置、`smoothStream` 分块、`experimental_streamSpeech` 文本输入、`decide` 状态与问题形状以及 batch reference version 等的类型检查；另发布 ai@6.0.317，更新依赖 `@ai-sdk/gateway@3.0.223`。[2][3] Retell 使用 OpenAI 模型支撑每月 1 亿通电话，GPT-6 Astra 在其语音智能体基准中领先，Codex 则帮助其达到每名员工 160 万美元的年化营收。[4] OpenAI 扩大与 Oracle 的合作，将商业应用和 AI 智能体引入 ChatGPT，并支撑 Oracle 的新服务。[5]

## 全栈 / 运行时

Cloudflare 推出与漏洞赏金计划结合的 PHP Capture the Flag 挑战，邀请安全研究人员绕过其 WAF 防护并夺旗，以测试防护并帮助提升互联网安全。[6] Cloudflare 还基于 Cloudflare Radar 复盘 2026 年第三季度全球互联网中断，分析电力故障、自然灾害和政府关停如何影响网络连通性与流量。[7]
