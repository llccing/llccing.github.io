React 发布 19.0.9 版本，改进了 React Server Components 的传输协议。[1] 该更新由 @unstubbable 和 @eps1lon 贡献，值得使用服务器组件的开发者关注。

## AI

Simon Willison 推出 Chirp Pong 实验，这是一款双人竞技乒乓类游戏，两名玩家使用靠近的手机，通过 Web 麦克风 API 解释的音频噪音发送游戏状态，并添加图形和玩法变化使其更有趣。[2] OpenAI 推出 Rosalind Academic Plan，为符合条件的学术实验室提供 GPT-Rosalind 的赞助访问及工具，以推进生命科学研究。[3] Vercel AI SDK 发布 ai@6.0.308 和 ai@7.0.142 补丁，恢复原始 OpenAI 自定义工具输入 deltas，将流式输入标记为 text 编码以便 UI 客户端逐步显示而无需 JSON 解析，并在保存和恢复部分 UI 消息时保留该编码。[4][5] Anthropic 告知投资者季度收入增长近 50% 至 168 亿美元，即将 IPO，其中 Q1 收入约为 48 亿美元。[6] OpenAI 庆祝教师节，推出巴西葡萄牙语版 AI for Educators，Study Mode 可帮助教师支持学生通过问题进行主动、逐步的思考和学习。[7]

## 全栈 / 运行时

Cloudflare Gateway 和 Data Loss Prevention 通过与 Cloudflare Developer platform 的全栈集成，继承了 Cloudflare Workers 的灵活性和能力，成为完全可编程的安全 Web 网关。[8] Cloudflare 推出 Void，这是一个开源 SDK、CLI 和自托管平台，用于构建全栈 Vite 应用并将其部署到 Cloudflare。[9]
