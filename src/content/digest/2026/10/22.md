## Web / 框架

Vite 发布了 v8.3.5，修复构建阶段对缺失 chunk import maps 的处理、将 preload 依赖纳入 chunk import map 哈希，以及在 bundled-dev 模式下把 `server.origin` 应用到资源 URL 等问题。[1] 同期还发布了 Vite v6.4.5。[2] 这些修复关系到产物哈希稳定性与开发、构建环境下的资源地址正确性，使用 Vite 的项目值得关注并升级。

## AI

OpenAI 介绍了如何与分发合作伙伴协作，以维护一致的安全保障、支持负责任访问，并澄清使用政策中的预期。[3] 另有一篇说明 AT&T 与 OpenAI 合作，由 LegalEdge 团队重新思考法律工作接入并规模化法律判断，使法律知识更易获取。[5] Vercel AI SDK 发布 ai@5.0.279，在 transform 调用 `stopStream()` 后停止转发已缓冲的源流片段，避免 finish 事件之后仍出现文本或错误；ai@7.0.148 则更新了相关依赖。[7][8] Simon Willison 提醒 PHP 8.x 全线发布安全更新，修复两个远程代码执行漏洞；因协调披露过程泄露，利用代码已自昨夜流传，运行 PHP 的环境应立即升级。[4] 他还提到昨日以 Apache 2.0 许可发布的 Battle Drones 已出现法语分支 Panache，将游戏重绘为约 1900 年法国 Belle Époque 蒸汽朋克风格并加入动画开场，可在移动端和浏览器运行。[6]

## 全栈 / 运行时

Cloudflare WAF 新增完整事务检测，可将一次 HTTP 请求与其响应对应起来，从而发现仅检查请求时容易漏掉的成功利用、数据暴露和风险配置。[9] Cloudflare 还在公开披露前，为新披露的 PHP 漏洞部署了默认 WAF 防护，规则结合请求与响应信号以阻止利用尝试，并防止暴露数据到达攻击者。[10] Node.js 于 2026-10-21 发布 26.12.1（Current）、24.22.1 Krypton（LTS）和 22.23.4 Jod（LTS）三个安全版本，修复包括 tls 拒绝非规范 IP 地址、dns resolve 输入空字节校验、tls IP 规范化回归、http agent 数据保护、brotli 解码器相关问题等多项高危漏洞；LTS 版本还包含 permission 模型在 `realpathSync` 中的检查以及跨 snapshot 重置随机缓存等修复。[11][12][13] TornadoVM 7.0 发布，作为面向 Java 的开源异构编程框架，可自动在多核 CPU 与 GPU 上加速 Java 程序，并提供可与 Temurin、Red Hat OpenJDK、Coretto、Oracle、GraalVM、Zulu 等主流 JDK 配合使用的 GPU 编程生态。[14]
