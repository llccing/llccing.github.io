## AI

OpenAI 发布了面向 GPT-6 系列的模型指南，说明初创公司如何选择 GPT-6 模型、调节推理力度、改进提示与技能、协调工具，并为生产工作流做准备。[1] Chatham Financial 则使用 Codex 与 GPT-5.6 构建技术并重新设计工作流，将交易验证从 30 分钟缩短到 4 分钟以内。[2] 前者给出选型、调参与生产化路径，后者用资本市场场景中的耗时压缩说明落地效果，二者都指向大模型如何进入实际工作流。

## 全栈 / 运行时

Cloudflare 通过 Streamline 演示如何将 Workers、Durable Objects 与容器化媒体引擎搭配，搭建长时间运行、持续处理的自定义视频流水线。[3] AI Gateway 现已支持原生 Web Search API 集成，合作方为 Ceramic.ai、Exa 和 Linkup，开发者可通过 AI Gateway、REST API 或 Workers bindings，在模型推理调用中注入实时网页上下文。[4] 一项扩展边缘侧长时视频处理，一项把联网检索接到推理路径，运行时与 AI 网关能力因此同时向前推进。
