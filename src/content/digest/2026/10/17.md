## Web / 框架

Vue 核心发布了 v3.6.0-rc.12，属于 3.6 预发布。[1] 稳定版变更以主分支 CHANGELOG 为准，预发布变更则记录在 minor 分支 CHANGELOG 中，便于与稳定通道区分跟踪。[1]

## AI

Vercel AI SDK 发布 ai@7.0.143：在首次访问时生成默认 chat ID，使 `useChat()` 可在渲染未使用该 ID 时预渲染且不必读取随机值；为 `streamText` 增加 `experimental_lowMemory: true`，用于无回放缓冲、不保留最终内容结果的单消费者流式传输以降低内存占用；并为 TypeSafe AI 增加带图像边界的 `box` 决策问题类型。[2] 同期的 ai@6.0.309 主要同步了 provider-utils 与 gateway 依赖。[3] OpenAI 介绍巴西 Itaú 通过对话界面 ia.i 与治理平台 IARA，将 AI First 策略应用于全体客户与员工，落地于该国监管最严的行业之一。[4] 两名工程师借助 Codex 在数周内交付 Stack Overflow for Agents，其 ChatGPT 插件使注册增至三倍，agent 创建最高可达约 10 倍增长。[5] Simon Willison 推出 LaTeX renderer，灵感来自 Paul Ford 与 Aboard Foundary 的 Tiny Little Office：该应用提供文字处理、大纲、演示、表格、计算器、绘图、图表、动画、日历与行程规划等网页编辑器，并把文档数据存在 URL 的 fragment 中，使文档可收藏、可分享。[6]

## 全栈 / 运行时

Cloudflare 指出身份本身不能保证机器人行为负责，因此推出持续评估机制，检查 Verified bots 是否遵守 robots.txt 与 HTTP 429 等站点偏好，使其长期保持可问责。[7] 该公司还与 OpenAI 合作，帮助 AI 发现有用内容、跟上站点变更并减少无效请求，从而改善用户与网站所有者的体验。[9] Helidon 27 是首个遵循 Oracle Tip Tail 库开发模型的版本：Tip 采用最新 Java 技术，Tail 提供更稳定、更安全的基线；该版本与 JDK 27 同期发布，引入 Helidon Messaging、Helidon Data JDBC 等主要新模块，并重构了编程模型。[8]
