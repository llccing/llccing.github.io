## 人工智能

OpenAI 正在改进 ChatGPT 在低资源编程语言上的编码能力，并新增面向软件工程、SQLite 以及 COBOL 迁移的评测。[4] Vercel AI SDK 发布补丁：ai@6.0.311 修复了 `streamText` 的 transform 调用 `stopStream` 后仍继续发出缓冲流片段的问题，ai@7.0.145 则更新了依赖 `@ai-sdk/gateway@4.0.118`。[2][3] Simon Willison 转述 Jeremy Scheff 对编程职业的“讣告”式观察：编码智能体让职业程序员失去了过去靠棘手逻辑谜题获得高回报、且普通人难以替代的工作乐趣。[1] 他还发布了 web-edit 0.1a2，这是用于浏览和编辑文件夹内文件的小型 Web 应用，主要为通过 Tailscale 在不同机器上改文件而建，此次新增了文本与图像数据的“复制到剪贴板”选项。[5]

## 全栈 / 运行时

InfoQ 10 月 12 日这一周的 Java 动态提到，三项 OpenJDK JEP 已面向 JDK 28；同时还有 Azul Payara 2026 年 10 月版，Gatherers4j、Yupiik Fusion、Google ADK for Java 与 Google ADK for Kotlin 的点版本，以及 Apache Camel 修复的 38 个 CVE。[6] JEP 543 在 JDK 28 中将结构化并发定为最终特性，相对 JDK 27 无 API 变更，已在 JDK 27 上的团队只需去掉 `--enable-preview` 并重新编译；为 JDK 25 或 26 编写的代码则须适配 R_X 异常类型参数、ExecutionException 包装以及抽象的 timeout() joiner 回调。[9] Cloudflare 在 AI 代码审查每次运行成本翻倍后，通过提示缓存和智能模型路由将推理账单削减 68%，同时加快了审查速度。[7] 该公司还推出 Clairic，这是一类 System One 抽取模型，能够从非结构化输入中抽取、计算、估计并预测数据。[8]
